# 3201 — 作品アーカイブと世界観構築

このリポジトリは、貼り付けられた作品原稿をそのまま保存しつつ、
並行してその世界観(設定・用語・人物・地理・歴史など)を整理していくためのものです。

作業手順(引き継ぎ用)は `CLAUDE.md` を参照。

## ディレクトリ構成

- `原稿/` — 貼り付けられた作品本文を、受け取った順に改変せず保存する
  - ファイル名は `NNN_タイトル.md`(NNN は受け取り順の連番)
- `世界観/` — 原稿から読み取れる設定を整理したノート
  - `00_概要.md` — 世界観の全体像
  - `01_用語集.md` — 固有名詞・用語
  - `02_人物/` — 登場人物(陣営別に分割)
    - `00_主要人物.md` — やる夫・やらない夫・つかさ・かがみと家族
    - `01_陰陽寮.md` — 首脳部・地区長・その部下・2ch町の職員・政府と国外代表(第2部)
    - `02_組織.md` — 敵対組織のトップ・幹部・実行役
    - `03_民間退魔師・町の人々.md` — 呪具師・民間退魔師・一般人
    - `04_妖魔・妖精・その他.md` — 陣営に属さない妖魔・妖精、正体不明、メタ
  - `03_地理.md` — 場所・地名
  - `04_歴史・年表.md` — 時系列
  - `05_社会・制度.md` — 組織・文化・技術・魔法など
  - `99_未確定・矛盾メモ.md` — 判断保留の点、原稿間で食い違う点

## 運用ルール

1. 原稿は一字一句そのまま `原稿/` に保存する(誤字も直さない)
2. 世界観ノートは「原稿に書かれていること」と「推測」を区別して書く
3. 新しい原稿が来るたびに世界観ノートを更新し、根拠となる原稿ファイル名を添える
