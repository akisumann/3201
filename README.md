# 3201 — 作品アーカイブと世界観構築

このリポジトリは、貼り付けられた作品原稿をそのまま保存しつつ、並行してその世界観（設定・用語・人物・地理・歴史など）を整理していくためのものです。

作業手順は `CLAUDE.md`、世界観ノートの詳しい案内は `世界観/README.md` を参照。
2026-09-17から、**ストーリー全体を読まなくても安全にできる整理**を先行しています。内容の削除・圧縮・伏線の最終判定は全編確認後に行います。

## ディレクトリ構成

- `原稿/` — 作品本文を投稿順に改変せず保存
  - `NNN_タイトル.txt`
- `世界観/`
  - `README.md` — 世界観ノート全体の案内と安全整理ルール
  - `00_概要.md` — 世界観の全体像。旧運用の各話記録も残るため全編確認前は大規模編集しない
  - `01_用語集.md` — **旧用語集・保全用。新規追記は原則しない**
  - `01_用語集/` — 2026-09-17以降の用語追記先
    - `00_基本原理.md`
    - `01_組織・役職.md`
    - `02_術・呪具.md`
    - `03_妖魔.md`
    - `04_固有名詞・その他.md`
  - `02_人物/` — 登場人物。`README.md` に将来の人物単位整理方針
  - `03_地理.md` — 場所・地名
  - `04_歴史・年表.md` — 旧年表本文を保全
  - `04_年表/README.md` — 年表を必要な行範囲だけ読むための索引
  - `05_社会・制度.md` — 組織・文化・技術・魔法など
  - `06_あらすじ.md` — 今後の各話・各章の物語進行専用
  - `99_未確定・矛盾メモ.md` — **旧未確定メモ・保全用。新規追記は原則しない**
  - `99_未確定/` — 2026-09-17以降の追記先
    - `00_未回収の伏線.md`
    - `01_矛盾・要注意.md`
    - `02_解決済み.md`
    - `03_話者表記.md`

## 運用ルール

1. 原稿は一字一句そのまま保存する（誤字も直さない）。
2. 世界観ノートは「原稿に書かれていること」と「推測」を区別する。
3. 根拠となる原稿番号・レス番号を可能な限り添える。
4. 各話の出来事は原則 `06_あらすじ.md`、世界全体に必要な要点だけを `00_概要.md` に置く。
5. 全編確認が終わるまで、既存情報・引用・出典・提供者の指摘・重複記録を「不要」と判断して削除しない。
6. 旧 `01_用語集.md` と旧 `99_未確定・矛盾メモ.md` は凍結し、新規情報は分割ディレクトリ側へ追記する。
