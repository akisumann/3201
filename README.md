# 3201 — 作品アーカイブと世界観構築

このリポジトリは、貼り付けられた作品原稿をそのまま保存しつつ、並行してその世界観（設定・用語・人物・地理・歴史など）を整理していくためのものです。

作業手順は `CLAUDE.md`、世界観ノートの詳しい案内は `世界観/README.md` を参照。
2026-09-17から、**ストーリー全体を読まなくても安全にできる整理**を先行しています。内容の削除・圧縮・伏線の最終判定は全編確認後に行います。

## ディレクトリ構成

- `原稿/` — 作品本文を投稿順に改変せず保存
  - `NNN_タイトル.txt`
  - `旧版/` — 修正版が来たときの旧版
  - `README.md` — 全原稿の表（連番・受領日・内容要約・元ファイル名・chapter注記）
- `tools/`
  - `check_notes.py` — ノートの点検スクリプト。作業前とコミット前に走らせる
  - `stamp_unchecked.py` — 個人ファイルの「未突き合わせ」の断り書きを一括で付ける
- `世界観/`
  - `README.md` — 世界観ノート全体の案内と安全整理ルール
  - `00_概要.md` — 世界観の全体像（約10KB）
  - `00_概要_旧記録.md` — 旧概要の話別記録。**保全用**。照合済みだが台詞の保管庫として残す
  - `01_用語集.md` — **旧用語集・索引。本文は `01_用語集/` へ移行済み**
  - `01_用語集/` — 用語の正本
    - `00_基本原理.md` / `01_組織・役職.md` / `02_術・呪具.md` / `03_妖魔.md` / `04_固有名詞・その他.md`
  - `02_人物/` — 登場人物
    - `個人/<人物名>.md` — **1人1ファイル。ここが正本**
    - `モブ・集団.md`
    - 陣営別の旧ファイル（`00_主要人物.md` など）は索引化済みで本文は無い
    - `README.md` — 人物ノートの書式・統合した重複ファイルの表・別人の表
  - `03_地理.md` — 場所・地名
  - `04_歴史・年表.md` — 年表の正本。本編は部ごとの節に分かれている
  - `04_年表/`
    - `README.md` — 節の一覧と追記ルール
    - `旧_歴史・年表.md` — 並べ替え前の版。**保全用**
  - `05_社会・制度.md` — 組織・勢力／情勢の推移／文化・宗教／技術・魔法／メタ法則
  - `06_あらすじ.md` — 索引（原稿番号と話数の対応表）
  - `06_あらすじ/` — あらすじの本文。部ごと
  - `07_読書スナップショット/` — 読んだ時点の理解を固定した記録
    - `NNN-NNN.md` — 原則5話ごと
    - `統合/` — 部・章単位の中間層
  - `99_未確定・矛盾メモ.md` — **旧メモ・索引。本文は `99_未確定/` へ移行済み**
  - `99_未確定/`
    - `00_未回収の伏線.md` / `01_矛盾・要注意.md` / `02_解決済み.md` / `03_話者表記.md`

## 運用ルール

1. 原稿は一字一句そのまま保存する（誤字も直さない）。
2. 世界観ノートは「原稿に書かれていること」と「推測」を区別する。
3. 根拠となる原稿番号・レス番号を可能な限り添える。
4. 各話の出来事は原則 `06_あらすじ/`（`06_あらすじ.md` は索引）、世界全体に必要な要点だけを `00_概要.md` に置く。
5. 全編確認が終わるまで、既存情報・引用・出典・提供者の指摘・重複記録を「不要」と判断して削除しない。
6. 旧 `01_用語集.md` と旧 `99_未確定・矛盾メモ.md` は凍結し、新規情報は分割ディレクトリ側へ追記する。
