# 用語集

旧来の `../01_用語集.md` の本文はこのディレクトリの5ファイルへ移行済み。旧ファイルは索引として残っている。

2026-09-18に、各ファイルにあった「新規追記分」と「旧用語集からの移行分」の二表を**一表へ統合**した。以後この5ファイルが用語集の正本。

- `00_基本原理.md` — 開眼、妖魔の成り立ち、霊視、法力など世界の基本法則
- `01_組織・役職.md` — 陰陽寮、国外組織、役職、ライセンス、ランクなど
- `02_術・呪具.md` — 魔術・呪術・道術・陰陽術、能力、呪具、術式など
- `03_妖魔.md` — 妖魔の分類、種族、個体に関する用語
- `04_固有名詞・その他.md` — 上記に入らない固有名詞・呼称

## 運用

1. 追記前に、該当ファイルに同じ用語の行が既にあるか確認する（用語名の重複は現在ゼロ）。
2. 既存用語に情報が増えた場合は、その行へ `**第N部第M話**:` の形で追記し、出典を並べる。新しい行を作らない。
3. 新しい用語は表の末尾へ追加する。行はおおむね原稿番号順に並んでいる。
4. 作品全体の理解が必要な分類は無理に決めず、最も近いファイルに置いて「分類保留」と書く。

## 残っている不統一

- 「確定度」欄の書き方が揃っていない。旧用語集由来の行はほぼ `◎ / ○ / △` だが、新規追記分には「確定」「竜崎の説明」「使用結果は確定／体系詳細は未確定」など説明文が入っている行が100件近くある。記号へ寄せると「誰の説明か」「どこまで確定か」が落ちるため、機械的な変換は見送っている。
