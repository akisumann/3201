## 運用

1. まず旧 `01_用語集.md` に同じ用語があるか確認する。
2. 既存項目への追加であっても、旧巨大ファイルは原則更新せず、こちら側に「旧項目への追記」として出典付きで記録する。
3. 全編確認後に旧用語集と照合し、重複を統合して正式版へ移行する。
4. 作品全体の理解が必要な分類は無理に決めず、最も近いファイルに置いて「分類保留」と書く。

旧 `01_用語集.md` には現時点で `世界の基本原理 / 組織・役職 / 退魔師の術・呪具 / 妖魔の分類・個体 / 固有名詞・その他` の見出しが存在する。ただし後半には別分類の項目が混入しているため、全編確認前に機械的な移動はしない。
