# あらすじ分割ノート

`世界観/06_あらすじ.md` の後半に残っているプレースホルダを、安全に実内容へ置き換えるための分割ノートです。

## 方針

- 既存 `06_あらすじ.md` の第1部序盤〜中盤には既に詳細な各話要約が入っているため、丸ごと上書きして失う事故を避ける。
- 現収録分001〜112は読書スナップショット化済みなので、後半はその資料を根拠に正式な章・部あらすじをここへ作る。
- 将来的に `06_あらすじ.md` を一本化する場合は、旧本体・この分割ノート・`07_読書スナップショット/` を照合してから行う。
- 読書時点の印象や未確定事項は `07_読書スナップショット/` に残し、ここでは物語上の進行を中心に記録する。
