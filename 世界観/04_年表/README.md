## 追記のしかた

1. **どの節へ入れるか**
   - 新しい話で起きた出来事 → 「本編」の中の、その原稿が属する**部の節**。
   - **番外編は原稿番号ではなく時系列位置で決める**。過去の回想なら時代の節、本編の補完ならその部の節へ入れ、「番外6〜10の置き場所」の節に1行書いて所在をわかるようにする。
   - 回想で判明した過去の出来事 → 該当する時代の節（神話・古代／中世〜近世／近代／数十年前〜記念日直前）。本編の節には入れない。
   - 作中で予告された予定 → 「今後の予定」。実行されたら本編の該当部の節へ移す。
   - 作中時期が特定できないもの → 「時期不明・メタ情報」。
2. **「時期」列の書き方 — 絶対日付を探さない**
   - **提供者の指摘**: この作品には絶対日付がほとんど出てこない。第3部の「11月2日〜21日」「12月19日」「12月20日(火)」や番外10の「元旦」は例外的に明示された数少ない例で、本編の大半は日付が書かれていない。
   - よって「時期」列は**相対表記が正しい形**。`告示日` `同日` `直後` `翌日` `2ヶ月後` `残り30分` `第4部第N話` のように、作中で示された基準からの関係で書く。
   - 日付が原稿に明記されている場合だけ日付を書く。**無い日付を原稿から探したり、前後関係から逆算して日付を作ったりしない。**
   - 基準が何も無い話は `第N部第M話` だけで構わない。出典の原稿番号が順序を保証している。

3. **節の中での位置**
   - 各部の節は**出典原稿番号の昇順**に並べる。新しい話はふつう節の末尾に足す。
   - 「同日」「翌日」などの相対表記は、基準になる行の直後に置く。
   - 同じ原稿の中で複数の出来事を書く場合は、原稿内の順序を保つ。
4. **出典**
   - 列は `| 時期 | 出来事 | 出典 |` の3列。
   - 出典は**原稿番号**で書く（話数ではない）。**原稿030以降は「原稿番号−1」が話数**。第29話＝原稿030、第40話＝原稿041。
   - レス番号がわかる場合は `030 #344-384` の形で添える。
5. **新しい部が始まったら**
   - `### 第N部（原稿NNN〜NNN）` の節を作り、`| 時期 | 出来事 | 出典 |` と `|---|---|---|` の2行を置いてから追記する。
   - この README の表にも節を1行足す。
6. **粒度**
   - 年表は「いつ何が起きたか」の一覧。詳細は `../06_あらすじ/` 側に置き、年表には1話1〜2行の要約を書く。

## 読み方

全体を一度に読まず、必要な節だけを読む。部単位の節に分けてあるので、「第4部で何が起きたか」は第4部の節だけで足りる。
