## 追記のしかた

- 新しい話の出来事は「本編（記念日以降）」の節へ、出典原稿番号の順になる位置に入れる。
- 回想で判明した過去の出来事は、該当する時代の節へ入れる（本編の節ではない）。
- 作中で予告された予定は「今後の予定」へ。実行されたら本編の節へ移す。
- 「同日」「翌日」などの相対表記は、基準になる行の直後に置く。
