# 用語集

確定度:◎=作中で明言 / ○=文脈からほぼ確実 / △=推測

| 用語 | 意味・説明 | 確定度 | 出典 |
|---|---|---|---|
| 妖魔 | 妖怪・幽霊など、普通の人間には見えない超常存在の総称。作中表記は【妖魔】。「分かりやすく言えば妖怪」 | ◎ | 001 #113, #132-133 |
| 退魔師 | 妖魔を狩る者。「低位」「高位」等の位階がある(やらない夫は低位) | ◎ | 001 #114, #130 |
| 開眼 | 視えないはずの妖魔が見えるようになること。やる夫は引き篭もり10周年の深夜0時に開眼した | ◎ | 001 #11, #24 |
| 座敷童子 | 妖魔の一種。分類は「妖魔第2種・非敵対性妖魔」。基本的に無害。その種がいる家は栄え、出て行けば衰退する。原因は不明で「家主の幸運を全部使い切ったから出て行った」説もある | ◎ | 001 #132-133, #146 |
| 妖魔第2種 / 非敵対性妖魔 | 妖魔の分類の一つ。「簡単に説明すると、妖魔じゃない奴」とやらない夫は言う(=退魔対象ではない、の意か)。「真逆の存在」(敵対性妖魔)も存在する | ○ | 001 #146-147(半角カナ台詞) |
| 魔術 | 退魔師が使う技。やらない夫の「最強魔術」は指先に小さな火を灯す程度で、維持にも限界がある | ◎ | 001 #18-22 |
| 『アレ』『アイツら』 | やらない夫が内心で使う言葉。妖魔関係の危険を指す模様 | ○ | 001 #53, #66 |
| 備府出(読み不明) | 「クソ珍しい苗字」。謎の男がこの辺で活動している人物として探している | ◎(名前) / △(誰の苗字か) | 001 #23 |
| ニート記念日 | やる夫が引き篭もり10周年を祝う日。深夜0時に開眼した日でもある | ◎ | 001 #67-79 |
| 黄色い救急車 | 「頭がおかしい人を連れて行く」という俗説ネタ。やらない夫のギャグ | ◎ | 001 #172-187 |
