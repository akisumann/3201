# 用語集

確定度:◎=作中で明言 / ○=文脈からほぼ確実 / △=推測

## 世界の基本

| 用語 | 意味・説明 | 確定度 | 出典 |
|---|---|---|---|
| 妖魔 | 妖怪・幽霊など、普通の人間には見えない超常存在の総称。作中表記は【妖魔】。「一般人にはほとんど見えなくて、しかも人を殺すことも容易」。「変則的な生物」で子供もできるし種として進化もする | ◎ | 001 #113 / 002 #294 / 003 #391 |
| 妖魔の成り立ち | 全生物の生み出す感情から生まれる。最も生みやすいのは恐怖。生まれ方は(1)深層心理の感情から、(2)子供として、の2つ。感情は恐怖・信仰・愉悦・希望などが混ざることもあり、特定は困難 | ◎ | 003 #389-394 |
| 退魔師 | 妖魔を狩る者。位階がある(低位/中位/上位)。専業で成立する職業。退魔師の家系が存在する。やる夫は「2流の退魔師」にはすぐなれそうと評される | ◎ | 001 #114 / 002 #205, #233 / 003 #350 |
| 国営退魔機関 | 海外(イギリス・ドイツ)にある。日本より遥かに活発で、サキュバスはほとんど絶滅状態。日本にも国営機関があるかは不明 | ◎(海外) / △(日本) | 003 #365 |
| 開眼 | 視えないはずの妖魔が見えるようになること。開眼=退魔の才能がある。「この時代に新たに開眼する奴が出る」のは珍しい | ◎ | 001 #11 / 002 #235 / 003 #454 |
| 魔術 | 退魔師の技の一系統。やらない夫は苦手かつ「嫌い」。日本の退魔師は基本的に苦手。魔術書はレベルが高いと読むだけで危険(やる夫は吐血) | ◎ | 002 #218-220 / 003 #410-423 |
| 魔術書 | やらない夫の本棚にある。やる夫が開いた途端に吐血。つかさは読めて「サタニズム思想の本質」を理解しかけた。「英語?」に見える文字。内容は「悪魔協会のサタニズムとは違って本気でヤバイ方」で「サタニック儀式」の章もある | ◎ | 003 #408-423 |
| 呪術 | 退魔師の技の一系統。やらない夫の得意分野(肉体強化のみ)。指南書がある。やる夫は「のろい・お札」のイメージ | ◎ | 002 #219 / 003 #428-432 |
| 備府出流対妖魔呪術 | 備府出家の一子相伝(ただし「ほとんど漏れちゃった」)。肉体強化=マッチョになる呪術で、現在の日本ではやらない夫しか使っていないほど使い手が少ない。創始者は「最強の鬼を殴り殺した」と言い伝えられ、指南書には鬼との戦い方が書かれている | ◎ | 003 #429-432 |
| 対妖魔用の結界 | やらない夫が自宅の周りに張っている。つかさが素通りした(やらない夫は「壊れたのかな」) | ◎ | 003 #349 |
| 呪具 | 退魔に使う道具。高額 | ◎ | 002 #234, #310 |
| 霊障 | 霊的障害の略 | ◎ | 002 #286-287 |
| 依頼 | 退魔師は依頼を受けて退魔する。期限がある | ◎ | 002 #285 |

## 妖魔の分類・性質

| 用語 | 意味・説明 | 確定度 | 出典 |
|---|---|---|---|
| 妖魔の位階 | 下位・低位・中位(・上位?)。大多数の下位は知能がなく殺し合いになる。中位に近い低位は少し知能がある | ◎ | 002 #293, #310-312 |
| 秘中の妖魔 | やらない夫でも知らない妖魔がいる区分(「秘中の奴とかは知らんがな」) | ○ | 003 #358 |
| 静か/騒がしいタイプ | 人が入ってきたときの反応。騒がしくなるのは危険 | ◎ | 002 #292 |
| 妖魔第2種 / 非敵対性妖魔 | 妖魔の分類の一つ(座敷童子が該当) | ○ | 001 #146 |
| 座敷童子 | 家に宿り家主と訪問者に幸運を与える妖魔。家から出られない(はず)。減少傾向。負の感情から生まれた「座敷童子もどき」は幸運をもたらさない。元となった種は臼殺(子供の間引き)への恐怖から生まれた「ノタバリコ」「ウスツキコ」で、気味悪いだけの存在 | ◎ | 001 / 002 #247-249 / 003 #391, #395 |
| ノタバリコ / ウスツキコ | 臼殺への恐怖から生まれた、座敷童子の元となった種。気味悪いだけの存在 | ◎ | 003 #391 |
| 座敷童子狩り | 退魔師が座敷童子の幸運を欲して狩ること | ◎ | 002 #247 |
| サキュバス | 日本にはほとんど居ない。居るのは「清純なサキュバス」で、好きな人にくっ付いて来た既婚者ばかり。キリスト教圏(北欧など)に多い。イギリス・ドイツではほぼ絶滅 | ◎ | 003 #364-370 |
| ムーミン | フィンランドにいる。やらない夫いわく「俺たちじゃ100%勝てん」。ギャグの可能性大 | ◎(台詞) / △(設定) | 003 #365 |
| 鬼 | 備府出流の創始者が殴り殺したと言い伝えられる「最強の鬼」。指南書に戦い方がある | ◎ | 003 #431-432 |
| ゾンビ(妖魔) | 第2話の退魔対象。穏やかな性格の低位妖魔 | ◎ | 002 #299-312 |
