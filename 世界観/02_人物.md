# 人物

## 主要人物

- **やる夫**
  - 立場・所属:元ニート(25歳)。**開眼者**。極めたものは「ニート」(ニート十周年の深夜0時に人の枠を踏み外した)。「新しい退魔の術の創始者」で、世界中の退魔組織から引っ張りだこ、妖魔からは天敵として命を狙われる。新城の隠蔽の呪具で「2流程度」に見せている
  - 能力:魔術・呪術・道術・陰陽術すべて不可。ニート術(仮)の効果は未解明。第5話で弾の威力上昇と未来読みの無効化らしき現象。頑丈な体
  - 経済:**家は貧乏で家族に家から追い出された**。やらない夫に家を買わせた。やらない夫への借金は**約1億円**(FX全力空売り→政府介入で5000万円など)。年間遊戯費300万円。貯金0。ルルーシュ戦の弾代100万円も立て替え
  - 過去:10歳からいじめ。13歳頃やらない夫が転居。15歳で高校受験失敗、引き篭もり。18歳で再会(005)
  - 内面:新城の勧誘(国家公務員)を「今の日常を失うのも嫌」と断る。つかさの好意を「夢」と思うほど信じられない。「一人でも二人でも守る事には変わんねぇ」
  - 関係:やらない夫(唯一の友達・債権者)、つかさ(同居。間接キス済み)。アカギ・ルルーシュ・新城から注目
  - 苗字:不明
  - 出典:001-006

- **備府出やらない夫**(読み不明)
  - 立場・所属:低位の専業退魔師(民間)。備府出家の後継者
  - 能力:備府出流呪術(肉体強化)。新城の評価は「未知だが、あれも普通じゃない」。アカギの本命は(新城の推理では)やる夫ではなくやらない夫
  - 特徴:「〜だろ」「常識的に考えて」「JK」。煙草。開眼を羨む。**やる夫に家を買い与え、1億円貸している**(つかさ評「聖人君子か何か」)。実家は「いつものダイニング」がある家で和室もある
  - 過去:13歳頃、父の意向で行方を隠して転居、5年間音信不通
  - 出典:001-006

- **柊つかさ**(ひいらぎ つかさ)
  - 立場・所属:やる夫の家で生まれた座敷童子(規格外)
  - 特徴:おっとり。やる夫に密着し、食べかけのアイスを渡す(間接キス)。「私だってやる夫さんと一緒にいたい」。「(命を狙われるのは)おそろいだね♪」
  - 異常な点:家から出られる / やらない夫には化け物に見える / 結界を素通り / 魔術書を読める / 隠れたアカギを発見 / アカギの「またアイツ」。**新城は「特に変な目で見てなかった」**(やらない夫談)
  - 正常な点:一般人には見えない。幸運を呼ぶ。アカギ・ルルーシュ・新城が座敷童子と認識
  - 出典:001-006

## 陰陽寮関係者

- **新城直衛**(しんじょう なおえ)
  - 立場:**東北の地区長**。予告#24の「新城さん」。第4話の「退魔関係者」(山で会った人物)と同一。第4話の「監視者(東北の地区長)」とも同一(○)
  - 能力:読唇術。高い法力。反魂の術(死者蘇生)を「便利だよね」と言う。やらない夫は「実はもう人じゃない」と疑う。気配を消す部下がいる
  - 表の行動:アカギの無謀な依頼を「殺そうとしたと言ってもいい」と謝罪。やる夫たちを調査済み。やる夫を陰陽寮に勧誘し、断られると「見なかったことにする」。隠蔽の呪具を渡し、連絡先を教える。敬語を使わない
  - 本音:「僕が来たのはアカギさんの情報が欲しかったから」。「アカギさんはやらない夫君目当てだったか……なぜ?」。「僕は恩を売ったんだよ。あいつらは上ってくるぞ。やる夫君は世界でも指折りの存在まで」。「あいつら目を離してないといいが」(誰かに監視させている ○)
  - やる夫の評価:「実績上、普通の退魔師でしかない。たしかにナニカ隠しているようだが」「よくそんな武装で撃退できたな……それもやる夫君の才能か?」
  - 出典:001 #24 / 004 / 006

- **新城の部下(謎の人物)**:気配を消して現れる。新城の放置策を「餌か」「運が悪ければあいつら殺されるぞ」と評す。出典:006 #893-898
- **新城の部下たち**:ルルーシュ(件)を追っているが捕まらない。出典:006 #850

- **アカギ**(関東地区退魔師監査委員長)
  - 第4話参照。「今まで全く働かないことで有名」だったが最近動き出し、組織の地方幹部を今週3人倒した。「上に報告するなんてつまらないことをする人ではない」(新城)。裏で化物と契約
  - 出典:001 / 003 / 004 / 006 #940

## 「組織」(陰陽寮の敵対組織)

- **ルルーシュ・ランペルージ / ゼロ**
  - 種族:**件(くだん)**。予言をしても死なない
  - 立場:組織の**地方幹部**(自称「下働き」はプライドの高さゆえ「トップ以外すべて下働き」)。組織内では「ゼロ」。「実力が無い俺でも成り上がることは可能」と自覚
  - 街中で戦わなかった理由:町に東北の地区長(新城)が来ていたため「私闘に巻き込む必要はない」
  - 決意:「待ってろよ、白饅頭! 必ず見返してやる」
  - 出典:005 / 006 #833-856, #937-948

- **死神**:組織の上位者らしい妖魔。ゼロを呼び出して問い詰める。陰陽寮対応で「大忙し」。魔人と険悪。出典:006 #937-943
- **魔人**:組織の妖魔。一人称「我が輩」。働かない。「面白くなってきた」と喜ぶ。死神と険悪。出典:006 #940-942
