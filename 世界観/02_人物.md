# 人物

## 主要人物

- **やる夫**
  - 立場・所属:元ニート(25歳、引き篭もり10年)。開眼して退魔師を目指す民間の退魔師見習い
  - 特徴:瀕死になっても復活する頑丈な体。妖怪辞典は1週間で読破。**魔術・呪術・道術・陰陽術がすべて使えない**。武術も付け焼刃。「変なとこで自分に自信ない」「気骨がない」(やらない夫評)
  - **アカギの示唆**:「お前には全部合わねぇ」「たまには自分で路を切り開いてみたいと思わないのか」「喜べ白饅頭。お前が(先頭を行く)それだ」。やらない夫の推測では「まったく新しい術」の創始者で、偉業はすでに達成済み
  - 先祖:退魔師の才能は親から受け継ぐため、先祖に必ず退魔師がいる(流派は不明。仮に「入速出流」)
  - 動機:退魔師になればモテる。「適度にがんばってモテモテになる予定」で本気で修行する気はない
  - 関係:やらない夫は親友(「仲いいとか絶対ない」と同時に言う)。つかさと同居。アカギに「白饅頭」と呼ばれる
  - 苗字:不明(「入速出」は仮称)
  - 出典:001-004

- **備府出やらない夫**(読み不明)
  - 立場・所属:低位の専業退魔師。**民間**。「田舎の一地方で細々と活動する無名退魔師」。備府出家の後継者
  - 能力:備府出流呪術(肉体強化)。呪具を山ほど使ってもねこまたには「6割近い確率で負ける」。自宅に結界。魔術は嫌い
  - 特徴:「〜だろ」「常識的に考えて」「JK」。煙草。懸賞・宝くじに当たりまくる。アカギに「白長」と呼ばれ、頭が上がらない。つかさは化け物に見える
  - 哲学:「妖魔も人間と同じで色々いる」「幸せは自分で掴み取る」
  - 出典:001-004

- **柊つかさ**(ひいらぎ つかさ)
  - 立場・所属:やる夫の家の座敷童子(とされる)。親はおらず「気がついたらやる夫さんの部屋にいた」
  - 特徴:おっとり。幸運は無意識。「幸運を呼ぶだけで不運は寄せ付けない」。ケーキが好き。やる夫が死ぬのも視えなくなるのも嫌
  - **異常な点(積み重なる謎)**:
    1. 座敷童子なのに家から出られる(002)
    2. やらない夫の目には巨大な化け物に見える(002 #279, 004 #535-536)
    3. やらない夫の対妖魔用結界を素通りした(003 #349)
    4. やる夫が吐血した魔術書を読めた(003 #418-422)
    5. **気配を消して隠れていた関東地区長アカギを「なんとなく」で見つけた**(004 #519-533)。アカギ「実力差なんて比べるまでも無い」相手に捕まった
    6. アカギの独白「またアイツ、今回もアイツ、次回もアイツ?」(004 #534)=アカギはつかさ(または同種の存在)を以前から知っている可能性(△)
  - 正常な点:一般人には見えない。幸運を呼ぶ。アカギには「座敷童子」「小娘」と認識された
  - 出典:001-004

## 陰陽寮関係者

- **アカギ**(関東地区退魔師監査委員長/アカギ地区長)
  - 第3話の「謎の男」の正体。予告#23-24の男と同一
  - 特徴:煙草を吸う(屋上でしか吸えないと愚痴る)。「年寄り」と化物に呼ばれる。やる夫を「白饅頭」、やらない夫を「白長」と呼ぶ。気配を消して影から見守る。「ククッ」と笑う
  - 表の行動:関東の管轄外である2ch町に来て、やる夫とやらない夫を名指しで「ねこまた退治」(1500万円、所得税免除、2週間)に引き込もうとした。やる夫の開眼と「新しい術」の資質を知っている。「先人の言葉に従うのは悪くないが面白みに欠ける」「自分で路を切り開け」
  - **裏の行動**:ビルの屋上で「都を恐怖に染めあげた化物」と密会。化物と**契約**し、30年続く**捜索**に協力している。化物を一度殺している。「後3年もあればすべて終わる」。東北地区長に監視され「身動き取れん」ため捜索を中断
  - 独白:「今回の奴はかなりいい線だったんだがな」「面白いのも居たし……実に残念だ」→やらない夫(いい線)とやる夫(面白い)を何かに使うつもりだった(○)
  - 出典:001 #23-24 / 003 / 004

- **退魔関係者**(名前未登場)
  - 陰陽寮側の人物。一人称「僕」。「うちの者(アカギ)が迷惑を掛けていなかったか」と言うので、アカギの部下または同組織。アカギを緊急で呼び出し、管轄外の依頼を問い詰めてキャンセルさせた。「全地区長が集まる場で釈明会」を開くと言う。やる夫たちに「後日謝罪に行く」
  - 出典:004 #544-557

- **監視者(東北の地区長)**
  - アカギの後方5,500メートルのビルからアカギを監視。読唇術が使える。アカギが「あの事件」に関わっているかを「黒に限りなく近いグレー」と見ている。「アカギ地区長が裏切ってないことを願いたい」。化物の妖気に驚く
  - 退魔関係者と同一人物かは不明(△)
  - 出典:004 #597-607

## 妖魔・その他

- **都を恐怖に染めあげた化物**(謎の相手)
