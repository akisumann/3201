# 人物

## 主要人物

- **やる夫**
  - 立場・所属:元ニート(25歳)。**開眼者**。極めたものは「ニート」(ニート十周年の深夜0時に人の枠を踏み外した)。「新しい退魔の術の創始者」で、世界中の退魔組織から引っ張りだこ、妖魔からは天敵として命を狙われる。新城の隠蔽の呪具で「2流程度」に見せている
  - 能力:魔術・呪術・道術・陰陽術すべて不可。**ニート術(仮)は言霊に酷似**し、命令を口にすると相手が従う(やらない夫を焼きそばパン買いに走らせた)。背後に魔法陣らしきものが出る。ルルーシュを「止まれ」で棒立ちにした。第5話の弾の威力上昇との関係は未確定。頑丈な体。「ニート力を上げる」秘密の修行。ネットにスレを立てて叱られた。「依頼人が美女なら…」と言ってつかさに窘められ素直に諦めた
  - 陰陽寮での扱い:「初心者」として下位退魔師用の怨霊退治を割り当てられた
  - 第13話:「あんな幼女、一発だお」と自分が殿を務めると言い張る。お札の幻覚でルルーシュを見せられ、あの時の怒りと痛みを再体験して言霊の条件を整える。「自害しろ」は不発、「黙れ」で少女の声を封じ、激怒すると黒い塊が噴き出した。つかさ(幻覚)が殺されたと思い泣いた。「つかさが無事ならそれでいいお」
  - 第14話:「生まれて25年、ここまで活躍したことがあっただろうか」と歓喜した後、「つかさを守れなかった」「もう無理、みんなで引き篭もる」と落ち込み、やらない夫に「黙って働けニート」「いま出来る事からしていけばいい」と叱咤される。受付のかまいたちに抗議。見舞金で「こんな大金見るの生まれて初めて」
  - 第11話:終了確認の空き家で妖魔の少女に閉じ込められる。やらない夫の「逃げろ」を合図に不意打ちする作戦を事前に決めていた(つかさには未共有)。ルルーシュの忠告が件の予言だと気づく。「つかさを危険に晒すのは認めない」と一人で出て行こうとする。つかさの「悪い人じゃない気がする」癖を「勘なんか当てにならねぇ、客観的に判断しろ」と叱る
  - 第9話:東京の空き家で怨霊を撃破し初仕事達成。弾を外した後「どうにかなるお」と言ったら弾がUターンして命中。やらない夫「すげぇ避け方」。「もう一流退魔師になった、修行終わり」と宣言(やらない夫「まだ始まってすらいない」)。ルルーシュがつかさを誘うのを見て「捨てられる」と危機感
  - 5年前(20歳):パソコンでレスバトルをし、モニターを殴り、「シコって寝よ」と言い、かがみとつかさに「いいケツしてんなぁ」と(見えていないのに)言う生活。二人の布団に潜り込もうとしてかがみに弾き出されていた。やらない夫に彼女ができて「デート行ってくる」と言われ嫉妬
  - 経済:**家は貧乏で家族に家から追い出された**。やらない夫に家を買わせた。やらない夫への借金は**約1億円**(FX全力空売り→政府介入で5000万円など)。年間遊戯費300万円。貯金0。ルルーシュ戦の弾代100万円も立て替え
  - 過去:10歳からいじめ。13歳頃やらない夫が転居。15歳で高校受験失敗、引き篭もり。18歳で再会(005)
  - 内面:新城の勧誘(国家公務員)を「今の日常を失うのも嫌」と断る。つかさの好意を「夢」と思うほど信じられない。「一人でも二人でも守る事には変わんねぇ」
  - 関係:やらない夫(唯一の友達・債権者)、つかさ(同居。間接キス済み)。アカギ・ルルーシュ・新城から注目
  - 苗字:不明

  - **殺傷事件との関係**:被害者の共通点「肉体強化系が得意」「不相応の依頼を受けた」に該当。新城は「被害者になりかけた彼」と呼ぶ。ルルーシュ相手には土下座級の下手に出る
  - 陰陽寮との関係:これまで陰陽寮から依頼を回してもらっていた。ライセンスあり。受付の天使から上位退魔師用(ねこまた群れ)、Bランク専用の依頼を勧められ拒否
  - 第13話:作戦立案者。お札の原理を解明して改造し、やる夫の言霊の条件を整え、つかさに分身の囮機能を仕込んだ。「一番弱いつかさが真っ先に狙われる」と予測。単独で妖魔の少女と渡り合い、少女に「技の撃ち方が人間じゃなかった」「魂は美味しそうな色、実力と噛み合ってない」と評された。「殿を受け持つなら俺だけでいい」
  - 第14話:退魔師**5年目**と明言。「改造中の記憶がところどころ無い」「あの時は幻術が相手を押さえつけてなかったか? 質量がある幻覚とか、それはもう幻術じゃない」と自分の改造を不審に思う。アカギ「途中からドンドン良くなった。白饅頭が乱入した後は完全にあの妖魔の動きを捉えていた。別人だ」。酒呑童子「あいつの子孫ならその程度の筈が無い」→**酒呑童子を殺した退魔師の子孫と目されている**。今回の戦闘で数百万円の赤字
  - 第11話:妖魔の少女の一撃で吹き飛ばされ、治療用・結界用呪具を使って大赤字。「戦った中で一番強い」「勝算は良くて1割以下」。指南書の中身を白状(「格好つけろ」だけ)。「本当に凄い人なら何代もあんな田舎で細々とくらしてない」。縮む体質は自分だけで「親父はそんなこと無かった」と疑問視。つかさの案(監視者に助けを求める)に賛成
  - 第9話:やる夫の能力について3仮説を立て「分からない」と結論。言霊で再現するには数千万円の呪具が要ると気づいて「どうにかなるお」を繰り返し錯乱。やる夫に話を聞かせるため本当に裸踊りをした(監視役が「両目が潰れた」)。呪具師の事情に詳しい
  - 特徴:「〜だろ」「常識的に考えて」「JK」。煙草。開眼を羨む。**やる夫に家を買い与え、1億円貸している**(つかさ評「聖人君子か何か」)。実家は「いつものダイニング」がある家で和室もある
  - 過去:13歳頃、父の意向で行方を隠して転居、5年間音信不通。再会後の5年前(20歳頃)には彼女がいてデートしていた

- **柊つかさ**(ひいらぎ つかさ)
  - 立場・所属:**5年前**、姉・柊かがみと共にやる夫の家で生まれた座敷童子。「自分が誰なのか、ここがどこなのか、よく分からないことばっかりで怖かった」。当初は家から出られず(見えない壁)、家主の観察しかすることがなかった
  - **過去(第12話)**:穏やかな日々が3か月続いた後、かがみが脱出方法を見つけて街へ連れ出してくれた。帰り道に球磨川に襲われ、かがみが自分を庇って腹を刺された。「早く帰りなさい」「あなたがいるとマトモに戦えやしない」と言われて逃げ、気づいたらやる夫の家に戻っていた。かがみは帰らなかった。「私は逃げたのだ」「二人で一緒に死んだだけだ、だからこれは正解」と自分に言い聞かせても後悔が止まらず、やがて「感情は風化する」ことを知り、そんな自分も嫌いだった。**誓い:「二度と大切な人を見捨てない。姉のように生き抜こう」**
  - 「気がついたらやる夫さんの部屋にいた」(003)は生まれた時の話で、矛盾はない。ただし第3話・第5話では姉の存在に触れなかった
  - 特徴:おっとり。やる夫に密着し、食べかけのアイスを渡す(間接キス)。「私だってやる夫さんと一緒にいたい」。「(命を狙われるのは)おそろいだね♪」。やる夫の危険なことには必ず反対する(好きだから、とやらない夫が指摘)。危険に身を置く修行案に「現実的に考えて確率は低い」と正論を言う
  - **「お姉ちゃん」**:第7話ラストの「ねぇ、お姉ちゃん……」、第11話の「お姉ちゃんも止めてよ」は柊かがみのこと。第11話で単独脱出案に固執したのは、姉を見捨てた後悔から「今度は自分が」という誓いによる
  - 人を見る目:アカギ、ルルーシュ、監視者のいずれも「悪い人じゃない気がする」と言い、「これでも人を見る目はあるつもり」。東京に来てからずっと監視されていることに気づいていた
  - 第11話の提案:自分だけ隠れて抜け出し、監視者に助けを求める(やる夫は反対)
  - 第13話:「私に大切な人を守らせて」「やる夫さんが死ぬのはもっとイヤ」。やらない夫の指示で部屋に隠れ、お札で自分の分身を囮にした。分身が殺され、やる夫が泣いたところで本物が現れる。指示になかった「幻覚を大量に出す」を独断で行い、やる夫と自分の幻覚で少女を包囲した。「本物は、私だよ?」。やる夫の「無事ならそれでいい」に姉の言葉を重ねた
  - 第14話:お札の使用に「凄い集中力」が必要で眠くなった。お札は消滅。姉のかがみが屋敷のすぐ外まで来ていたが会っていない
  - 索敵:第8話ラストでビル群の光に最初に気づく(読者「つかさは索敵強い」)。「時々消えかける」「背景になる」とメタにいじられる
  - 第9話:崇徳上皇の名を出してやる夫を驚かせた。「人が多いところは慣れない」。周りの目が気になって店で落ち着いて食べられなかった。ルルーシュの食事の誘いを「みんなで一緒にっていうのは?」と条件付きで受けかけた
  - 第10話:ルルーシュから「身に着けた妖魔を一般人が感知できるお札」を貰い、お礼に食事を奢る(カフェでスイーツを大量注文)。ランクは最下位付近(やらない夫評)。**ルルーシュの忠告「今日一日、絶対につかさを一人にさせるな」**の対象
  - 異常な点:家から出られる / やらない夫には化け物に見える / 結界を素通り / 魔術書を読める / 隠れたアカギを発見 / アカギの「またアイツ」。**新城は「特に変な目で見てなかった」**(やらない夫談)
  - 正常な点:一般人には見えない。幸運を呼ぶ。アカギ・ルルーシュ・新城が座敷童子と認識
  - 出典:001-006

  - 定例報告会での弁明:ねこまた依頼は「急いで解決したい案件で部下が忙しかった」「東京も物騒で腕のある奴は自らスカウトしている」「やらない夫の秘めた力はEランクの遥か上」「俺が犯人なら何の利益がある?」。ルイズ「やるならコイツじゃない」。「好きにしろ。だが、お前の手勢ごときで俺を監視しきれるか?」
  - 第4話参照。「今まで全く働かないことで有名」だったが最近動き出し、組織の地方幹部を今週3人倒した。「日本トップクラスの実力者」(監視役)。裏で化物と契約。「連続退魔師殺傷事件」への関与を疑われ、上位退魔師十数人に監視されている
  - 第11話(回想):依頼斡旋所で安藤が不相応な依頼を強要した際、イカロスに「そいつの言うとおりにしてやれ。この手の輩は相手するだけ時間の無駄だ」と指示。**不相応な依頼を止めない**態度は殺傷事件の被害者パターン(不相応の依頼を受けて死ぬ)と重なる(△)
  - 第8話:東京の空港でやる夫たちを「偶然」出迎え、陰陽寮まで案内。受付の天使に「マスター」と呼ばれる(天使はアカギの使い魔か従者 ○)。天使に「この三人を確実に覚えておけ」と2回念を押したが天使は「名前をメモしろ」と理解。「怪しまれるの覚悟で2回言ったんだぞ」と内心
  - **裏の顔(第14話で判明)**:契約相手は伝説の鬼・**酒呑童子**。契約内容は「捜索を手伝う代わりに、目的達成後は式神になる」。ねこまた依頼はやらない夫が「酒呑童子を殺した退魔師の子孫」か見極めるための試験だった。「白饅頭が乱入した後は完全にあの妖魔の動きを捉えていた。別人だ」とやらない夫を評価。殺傷事件は「俺じゃない」(酒呑童子も)。新城の時間差告発を「何か考えが有るんだろ」と読み、待機を選ぶ。「少し前に組織の地方幹部3人倒しただろ? 最低限のノルマは終わった」。ニンフに「一年中待機してないかしら」と言われる
  - 天使との関係:イカロス、ニンフは「マスター」の部下。天界から**麻雀**で連れて来た(神相手に天和を連発)。イカロスが勝手に見舞金として小遣い1000万円以上を渡した
  - 出典:001 / 003 / 004 / 006 #940 / 008 / 014 #2140-2166

## アカギの陣営(第14話)

- **酒呑童子**(しゅてんどうじ)
  - 第4話の「都を恐怖に染めあげた化物」の正体。伝説の鬼。1000年以上前に退魔師(備府出流創始者と推定 ○)に殺され、復活している
  - 目的:復讐ではない。「あの時は俺が弱かったから負けた」「もう負けるつもりはない。強くなったことをアイツに証明したい」。殺した退魔師の子孫を30年探している。「アイツが言ったように世のため、人のため働いてやろう」
  - 性格:「想像以上の脳筋」(アカギ)。妖力が漏れる。「気合が足りんぞ」。退魔師との戦いは歓迎するが一般人への被害は避ける。「業腹だがな」
  - やらない夫への評価:「あの白長の小僧も違ったな」と一度否定したが、アカギの「動きを捉えていた」に「あいつの子孫ならその程度の筈が無い!」と反応
  - 殺傷事件:「腹に穴が開いたとか、足が吹き飛んだとか、軽い怪我をさせちまった事は何度かあるが、死人は出してない」「模倣犯がいる。あるいは俺に濡れ衣」
  - 「アイツの所に麻雀でもしに行くか」→天界の神と麻雀をしている(○)
  - 出典:004 / 014 #2141-2166
- **ニンフ**:電子戦・情報戦特化の天使。アカギの部下。監視の目を誤魔化し、屋敷の戦闘を覗き見させた。「私、何してんだろ」「完全に陰陽寮に対する裏切り」と自覚しつつ従う。酒呑童子を「馬鹿じゃないの」と内心で罵り、「捜索中に死者を何十人も出すのはやりすぎ」と詰めた。出典:014 #2146-2166
- **イカロス**:「力押ししかできない脳筋」(ニンフ評)。やる夫たちを「マスターのご友人」と認識し、「後輩(かまいたち)の毒牙に掛からないように」と見舞金をマスターの小遣いから出した。出典:014 #2115-2139

## 「組織」(陰陽寮の敵対組織)

- **ルルーシュ・ランペルージ / ゼロ**
  - 種族:**件(くだん)**。予言をしても死なない
  - 立場:組織の**地方幹部**(自称「下働き」はプライドの高さゆえ「トップ以外すべて下働き」)。組織内では「ゼロ」。「実力が無い俺でも成り上がることは可能」と自覚
  - 街中で戦わなかった理由:町に東北の地区長(新城)が来ていたため「私闘に巻き込む必要はない」
  - 決意:「待ってろよ、白饅頭! 必ず見返してやる」
  - 第10話:カフェで三人と「仲直りの食事会」。つかさに一般人が感知できるお札を渡した。やる夫が退魔師3週間目と知り「赤子同然のルーキーに俺が負け」と衝撃。ランク制度を詳しく解説(自分のランクは「敵に言うはず無い」)。「人間の敵は人間だ」。別れ際に**忠告「後悔したくなければ、今日一日、絶対につかさを一人にさせるな」**。東京滞在を今日まで延長していた。C.C.に「友達でも助けに行ったのか」とからかわれる
  - 第9話:東京の街中でつかさと「偶然」再会し、再び食事に誘う(2度目の失敗)。「妖魔でも普通の人に認識させる方法はある」。つかさが「アカギと会った」と言うと驚くが、「あんな白饅頭が地区長のアカギと知り合いな訳ない」と誤解。妹の名は**ナナリー**。「こんなのに負けるようでは組織でも成り上がれない」
  - 出典:005 / 006 #833-856, #937-948 / 009 #1307-1322

- **球磨川**:5年前、かがみとつかさを襲った妖魔。『』の台詞。人の幸福を壊すのが目的。第14話で**「組織」のAランク妖魔**と判明。「可愛い子を捕まえて来い」と命令されており、かがみと組んでつかさの屋敷へ来た。「最近はどこに行っても可愛い子ちゃんを見なくなった。僕、頑張りすぎちゃった?」=座敷童子減少の実行犯の一人(○)。新城の奇襲で30秒で敗北し「かがみちゃん助けて」。出典:012 / 014 #2038-2084
- **C.C.**:ルルーシュと行動する妖魔。一人称「私」。ピザが好き。ルルーシュの行動を見透かしてからかう。組織との関係は不明。出典:010 #1453-1462
- **死神**:組織の上位者らしい妖魔。ゼロを呼び出して問い詰める。陰陽寮対応で「大忙し」。魔人と険悪。出典:006 #937-943
- **魔人**:組織の妖魔。一人称「我が輩」。働かない。「面白くなってきた」と喜ぶ。死神と険悪。出典:006 #940-942

## 妖魔・その他


- **やらない夫の父親**:秘密主義。出典:005
- **やる夫の家族**:貧乏。やる夫を家から追い出した。詳細不明。出典:006 #925, #932
- **受付のかまいたち**:第5話で捕獲された3匹のうちの1匹(切り裂き役)。仲間の1匹が女性用下着を数百回盗んだ罪で3匹とも捕縛され、この個体は情状酌量で陰陽寮本部の受付で働きながら釈放を待つ。陰陽寮の処置で喋れるようになった。やらない夫を「キモイ奴」「白長」と呼び、やる夫たちを「ゴミのような底辺の下位退魔師」と評して一番報酬の少ない仕事を回した。失敗した退魔師に「契約違反、違約金一億円」とハッタリをかけて再挑戦させる。「この仕事も悪くない」。出典:005 / 008 #1145-1160 / 009 #1185-1201
- **イカロス(受付の天使)**:陰陽寮の依頼斡旋所の受付。羽が生えている。アカギを「マスター」と呼ぶ。力量を読めるが、やらない夫を読もうとして煙を噴いた。マイペースで話が通じにくい。安藤に「Fランク相当」と正しく評価し危険だと止めたが、アカギの指示で依頼を渡した。出典:008 #1114-1157 / 011 #1481-1488
- **安藤**:正規ライセンス未取得(Fランク相当)の民間退魔師。「3000万円程度」の高額依頼を受付に強要し、妖魔に勝てず違約金1000万円に怯える。友人の入れ知恵で嘘の達成報告を思いつく。出典:011 #1478-1495
- **安藤の友人**:民間退魔師。「物音がする空き家の調査兼退魔」の依頼で嫌な予感がして切り上げ、倒さずに退魔報告をした=第11話の空き家。「終了確認は数十に1つ」と嘘を勧める。出典:011 #1490-1494
- **マスター(受付の奥)**:陰陽寮職員から「マスター」と呼ばれる人物。受付のかまいたちのハッタリを「嘘みたいなもんだが嘘ではない」と黙認し「不相応の依頼を受けて失敗する奴など使えん」と言う。第8話で天使が「マスター」と呼んだアカギと同一の可能性が高い(○)が名前は出ていない。出典:009 #1198-1200
- **失敗した退魔師 / 陰陽寮職員**:第9話の受付の場面の脇役。出典:009 #1191-1200
- **ねこまた / 猫耳の人物 / 山田 / ゾンビ / 備府出流の創始者 / 友人A・生徒たち**:第2〜5話参照
