# 人物

## 主要人物

- **やる夫**
  - 立場・所属:元ニート(25歳)。**開眼者**。極めたものは「ニート」(ニート十周年の深夜0時に人の枠を踏み外した)。「新しい退魔の術の創始者」で、世界中の退魔組織から引っ張りだこ、妖魔からは天敵として命を狙われる。新城の隠蔽の呪具で「2流程度」に見せている
  - 能力:魔術・呪術・道術・陰陽術すべて不可。**ニート術(仮)は言霊に酷似**し、命令を口にすると相手が従う(やらない夫を焼きそばパン買いに走らせた)。背後に魔法陣らしきものが出る。ルルーシュを「止まれ」で棒立ちにした。第5話の弾の威力上昇との関係は未確定。頑丈な体。「ニート力を上げる」秘密の修行。ネットにスレを立てて叱られた。「依頼人が美女なら…」と言ってつかさに窘められ素直に諦めた
  - 陰陽寮での扱い:「初心者」として下位退魔師用の怨霊退治を割り当てられた
  - 第9話:東京の空き家で怨霊を撃破し初仕事達成。弾を外した後「どうにかなるお」と言ったら弾がUターンして命中。やらない夫「すげぇ避け方」。「もう一流退魔師になった、修行終わり」と宣言(やらない夫「まだ始まってすらいない」)。ルルーシュがつかさを誘うのを見て「捨てられる」と危機感
  - 経済:**家は貧乏で家族に家から追い出された**。やらない夫に家を買わせた。やらない夫への借金は**約1億円**(FX全力空売り→政府介入で5000万円など)。年間遊戯費300万円。貯金0。ルルーシュ戦の弾代100万円も立て替え
  - 過去:10歳からいじめ。13歳頃やらない夫が転居。15歳で高校受験失敗、引き篭もり。18歳で再会(005)
  - 内面:新城の勧誘(国家公務員)を「今の日常を失うのも嫌」と断る。つかさの好意を「夢」と思うほど信じられない。「一人でも二人でも守る事には変わんねぇ」
  - 関係:やらない夫(唯一の友達・債権者)、つかさ(同居。間接キス済み)。アカギ・ルルーシュ・新城から注目
  - 苗字:不明
  - 出典:001-006

- **備府出やらない夫**(読み不明)
  - 立場・所属:低位の専業退魔師(民間)。備府出家の後継者
  - 能力:備府出流呪術(肉体強化)。やる夫の言霊を途中でレジストできた。**Eランク**(過去の実績だけの書類審査)。**隠された力量**:新城「未知だが普通じゃない」、受付の天使が読めず煙を噴く、アカギが定例報告会で「秘めた力はその遥か上、上位退魔師になっていない方が不思議」と公言。本人は「下位退魔師」を自認
  - **殺傷事件との関係**:被害者の共通点「肉体強化系が得意」「不相応の依頼を受けた」に該当。新城は「被害者になりかけた彼」と呼ぶ。ルルーシュ相手には土下座級の下手に出る
  - 陰陽寮との関係:これまで陰陽寮から依頼を回してもらっていた。ライセンスあり。受付の天使から上位退魔師用(ねこまた群れ)、Bランク専用の依頼を勧められ拒否
  - 第9話:やる夫の能力について3仮説を立て「分からない」と結論。言霊で再現するには数千万円の呪具が要ると気づいて「どうにかなるお」を繰り返し錯乱。やる夫に話を聞かせるため本当に裸踊りをした(監視役が「両目が潰れた」)。呪具師の事情に詳しい
  - 特徴:「〜だろ」「常識的に考えて」「JK」。煙草。開眼を羨む。**やる夫に家を買い与え、1億円貸している**(つかさ評「聖人君子か何か」)。実家は「いつものダイニング」がある家で和室もある
  - 過去:13歳頃、父の意向で行方を隠して転居、5年間音信不通
  - 出典:001-006

- **柊つかさ**(ひいらぎ つかさ)
  - 立場・所属:やる夫の家で生まれた座敷童子(規格外)
  - 特徴:おっとり。やる夫に密着し、食べかけのアイスを渡す(間接キス)。「私だってやる夫さんと一緒にいたい」。「(命を狙われるのは)おそろいだね♪」。やる夫の危険なことには必ず反対する(好きだから、とやらない夫が指摘)。危険に身を置く修行案に「現実的に考えて確率は低い」と正論を言う
  - **「ねぇ、お姉ちゃん……」**(007 #1015):第7話ラストで誰かに呼びかけた。相手不明。第8話では回収されず
  - 索敵:第8話ラストでビル群の光に最初に気づく(読者「つかさは索敵強い」)。「時々消えかける」「背景になる」とメタにいじられる
  - 第9話:崇徳上皇の名を出してやる夫を驚かせた。「人が多いところは慣れない」。周りの目が気になって店で落ち着いて食べられなかった。ルルーシュの食事の誘いを「みんなで一緒にっていうのは?」と条件付きで受けかけた
  - 第10話:ルルーシュから「身に着けた妖魔を一般人が感知できるお札」を貰い、お礼に食事を奢る(カフェでスイーツを大量注文)。ランクは最下位付近(やらない夫評)。**ルルーシュの忠告「今日一日、絶対につかさを一人にさせるな」**の対象
  - 異常な点:家から出られる / やらない夫には化け物に見える / 結界を素通り / 魔術書を読める / 隠れたアカギを発見 / アカギの「またアイツ」。**新城は「特に変な目で見てなかった」**(やらない夫談)
  - 正常な点:一般人には見えない。幸運を呼ぶ。アカギ・ルルーシュ・新城が座敷童子と認識
  - 出典:001-006

## 陰陽寮首脳部(第10話の定例報告会)

- **麻呂**(陰陽頭)
  - 陰陽寮の頂点。平安時代から続く名家出身の退魔師。「〜でおじゃる」「だまりゃ!」。調停者として多数決には加わらない。殺人事件は警察の領分という方針。雑誌『陰陽寮のひと時』を出す。出典:010 #1332-1390
- **竜崎**(陰陽寮補佐)
  - 「今の陰陽寮、実質のトップ」(ルルーシュ)。ランク制度の設計者で「少し有能」(やる夫)。殺傷事件を「大した事件ではありません」「我々は警察じゃない」と言い切る。アカギに「貴方が犯人ですね!?」と迫るが「私もアカギ地区長を信じたい」とも言い、監視案を出す。内心「アカギは嘘を吐いている」「新城も何か隠している」。出典:010 #1347-1385, #1428-1438
- **シックス**(近畿地区長)
  - 古都京都を含む近畿担当。「人類は皆、兄弟だ」「私ならそんな事はしない」。アカギ支持。出典:010 #1338-1339, #1377
- **藍染惣右介**(中部地区長)
  - 霊地(立山、白山、木曽御嶽山、戸隠山)と霊峰富士を防護する中部担当。穏やかな口調でアカギ支持。「僕たちは仲間じゃないか」。出典:010 #1338-1339, #1377, #1386
- **博麗霊夢**(中国・四国地区長)
  - 出雲大社を守護し「妖怪の里、四国」を抑える。麻呂を刺激しないよう黙る。竜崎を「ムカつく」と思う。アカギを疑う。出典:010 #1340, #1351, #1376
- **平賀才人 & ルイズ**(九州地区長・臨時)
  - 「修羅の国、福岡」と沖縄を担当。他の地区長より格下で「化物集団に混じってる」と自覚。才人はアカギを信じ、ルイズは疑う。ルイズは監視に人を出せない(「実力者が居ないだけ」と麻呂)。出典:010 #1341-1342, #1359-1361, #1376-1388

## 陰陽寮関係者

- **新城直衛**(しんじょう なおえ)
  - 立場:**東北の地区長**。霊地「恐山」、妖魔の一大拠点「遠野」、非常時の食料庫・北海道を監督。部下から「東北は魔境」と言われる。予告#24の「新城さん」。第4話の「退魔関係者」(山で会った人物)と同一。第4話の「監視者(東北の地区長)」とも同一(○)
  - 能力:読唇術。高い法力。反魂の術(死者蘇生)を「便利だよね」と言う。やらない夫は「実はもう人じゃない」と疑う。気配を消す部下がいる
  - 表の行動:アカギの無謀な依頼を「殺そうとしたと言ってもいい」と謝罪。やる夫たちを調査済み。やる夫を陰陽寮に勧誘し、断られると「見なかったことにする」。隠蔽の呪具を渡し、連絡先を教える。敬語を使わない
  - 定例報告会:証人としてアカギを告発(3週間前、Eランクのやらない夫に中位妖魔の依頼を役職を名乗って押し付けた)。「僕のところから引き抜くのは止めてください」。直轄部隊10人をアカギ監視に出す。竜崎は「新城も何か隠している」と見ている
  - 本音:「僕が来たのはアカギさんの情報が欲しかったから」。「アカギさんはやらない夫君目当てだったか……なぜ?」。「僕は恩を売ったんだよ。あいつらは上ってくるぞ。やる夫君は世界でも指折りの存在まで」。「あいつら目を離してないといいが」(誰かに監視させている ○)
  - やる夫の評価:「実績上、普通の退魔師でしかない。たしかにナニカ隠しているようだが」「よくそんな武装で撃退できたな……それもやる夫君の才能か?」

- **監視役**(新城の部下。謎の人物と同一かは不明):第9話でやらない夫の裸踊りを見て「両目が潰れた」と撤退を申し出るが、通信相手に「続行しろ」と言われる。多数のモニターでやる夫たちを一人で監視。新城の指示で陰陽寮向かいのビルへ。「アカギ地区長が連続退魔師殺傷事件に関与してる疑い」「この対応はやりすぎ」「上位退魔師十数人でアカギを監視するのは非効率、東北が妖魔の巣になる」「アカギは日本トップクラスの実力者で監視に気づいているはず」「新城の狙いはアカギの動きを封じるためか?」と独白。策謀は「お偉いさんに任せる」。出典:008 #1093-1105
- **新城の部下たち**:ルルーシュ(件)を追っているが捕まらない。直轄部隊10人がアカギ監視へ。出典:006 #850 / 010 #1384
- **雲外鏡**:アカギの部下。埋もれた才能を探すのが上手く、全国で人材を探している。妖怪の名を持つ。出典:010 #1371, #1374

- **赤木しげる / アカギ**(関東地区退魔師監査委員長)
  - フルネームは**赤木しげる**(010 #1336)。首都東京を擁し「日本屈指の妖魔発生区域」関東担当。定例報告会に遅刻常習、国外まで人材発掘に行ってサボる。「自分が楽するためだけに全国から人材をかき集めておる」(麻呂)。部下に人材探しの上手い「雲外鏡」がいる
  - 定例報告会での弁明:ねこまた依頼は「急いで解決したい案件で部下が忙しかった」「東京も物騒で腕のある奴は自らスカウトしている」「やらない夫の秘めた力はEランクの遥か上」「俺が犯人なら何の利益がある?」。ルイズ「やるならコイツじゃない」。「好きにしろ。だが、お前の手勢ごときで俺を監視しきれるか?」
  - 第4話参照。「今まで全く働かないことで有名」だったが最近動き出し、組織の地方幹部を今週3人倒した。「日本トップクラスの実力者」(監視役)。裏で化物と契約。「連続退魔師殺傷事件」への関与を疑われ、上位退魔師十数人に監視されている
  - 第8話:東京の空港でやる夫たちを「偶然」出迎え、陰陽寮まで案内。受付の天使に「マスター」と呼ばれる(天使はアカギの使い魔か従者 ○)。天使に「この三人を確実に覚えておけ」と2回念を押したが天使は「名前をメモしろ」と理解。「怪しまれるの覚悟で2回言ったんだぞ」と内心

## 「組織」(陰陽寮の敵対組織)

- **ルルーシュ・ランペルージ / ゼロ**
  - 種族:**件(くだん)**。予言をしても死なない
  - 立場:組織の**地方幹部**(自称「下働き」はプライドの高さゆえ「トップ以外すべて下働き」)。組織内では「ゼロ」。「実力が無い俺でも成り上がることは可能」と自覚
  - 街中で戦わなかった理由:町に東北の地区長(新城)が来ていたため「私闘に巻き込む必要はない」
  - 決意:「待ってろよ、白饅頭! 必ず見返してやる」
  - 第10話:カフェで三人と「仲直りの食事会」。つかさに一般人が感知できるお札を渡した。やる夫が退魔師3週間目と知り「赤子同然のルーキーに俺が負け」と衝撃。ランク制度を詳しく解説(自分のランクは「敵に言うはず無い」)。「人間の敵は人間だ」。別れ際に**忠告「後悔したくなければ、今日一日、絶対につかさを一人にさせるな」**。東京滞在を今日まで延長していた。C.C.に「友達でも助けに行ったのか」とからかわれる
  - 第9話:東京の街中でつかさと「偶然」再会し、再び食事に誘う(2度目の失敗)。「妖魔でも普通の人に認識させる方法はある」。つかさが「アカギと会った」と言うと驚くが、「あんな白饅頭が地区長のアカギと知り合いな訳ない」と誤解。妹の名は**ナナリー**。「こんなのに負けるようでは組織でも成り上がれない」
  - 出典:005 / 006 #833-856, #937-948 / 009 #1307-1322

- **C.C.**:ルルーシュと行動する妖魔。一人称「私」。ピザが好き。ルルーシュの行動を見透かしてからかう。組織との関係は不明。出典:010 #1453-1462
- **死神**:組織の上位者らしい妖魔。ゼロを呼び出して問い詰める。陰陽寮対応で「大忙し」。魔人と険悪。出典:006 #937-943
- **魔人**:組織の妖魔。一人称「我が輩」。働かない。「面白くなってきた」と喜ぶ。死神と険悪。出典:006 #940-942
