# 世界観ノート案内

このディレクトリは、『やる夫は退魔師として開眼したようです』の原稿から抽出した設定・人物・時系列・あらすじを、用途別に参照するためのノート群です。

## 現在の整理段階

2026-09-17から、**ストーリー全体を読み終える前でも安全にできる整理**を先行して行っています。

この段階では、既存ノートにある情報・引用・出典・「提供者の指摘」を削除しません。また、伏線か矛盾か、どの情報が重要か、どの重複が不要かといった**作品全体の理解を要する判断は保留**します。

既存の巨大ファイルは当面そのまま残し、新しい参照先と運用ルールを先に整えます。全編確認後に、内容を照合しながら圧縮・統合します。

## まず見る場所

- `00_概要.md` — 世界の仕組み・勢力・主要な状況。現在は過去の運用の名残で話ごとの記録も大量に含む。
- `06_あらすじ.md` — 今後の**物語進行・各話要約の専用置き場**。既存の各話要約は、全編確認前には無理に移動しない。
- `01_用語集.md` — 固有名詞、能力、術、呪具、組織用語など。
- `02_人物/` — 人物ごとの情報。現状は陣営別の大きなファイルにまとまっている。
- `03_地理.md` — 場所・地名。
- `04_歴史・年表.md` — 作中世界の時系列。
- `05_社会・制度.md` — 組織、文化、制度、技術、魔法体系など。
- `99_未確定・矛盾メモ.md` — 未確定事項、伏線候補、矛盾候補、解決済み事項、話者表記の注意。

## 情報の置き場所

新しい原稿を処理するときは、同じ情報を何でも全ファイルに複製せず、まず主な置き場所を決めます。

- 物語が「何が起きたか」 → `06_あらすじ.md`
- 世界全体を理解するために必要な仕組み・勢力図・現在地 → `00_概要.md`
- 用語そのものの意味 → `01_用語集.md`
- 人物の立場・能力・関係・経歴 → `02_人物/`
- 場所 → `03_地理.md`
- 年代・事件順 → `04_歴史・年表.md`
- 制度・社会・組織運用 → `05_社会・制度.md`
- まだ答えが出ていない問い、食い違い、話者判定 → `99_未確定・矛盾メモ.md`

複数ファイルに関係する場合も、長い引用や詳細記録は原則として一か所に置き、他方は短い参照にする方針です。ただし、**既存の重複は全編確認が終わるまで削らない**でください。

## 安全整理でしてよいこと

- 新しい案内・索引ファイルを作る。
- 見出しや保存先のルールを決める。
- 明らかに機械的に判定できる分類を行う。
- 元情報を残したまま、新しいファイルへコピーして参照性を上げる。
- 新規追記の置き場所を整理し、これ以上巨大ファイルが無秩序に膨らむのを防ぐ。

## 全編確認後まで保留すること

- 既存記述の削除・大幅な圧縮。
- 「これは重要ではない」という判断。
- 伏線と矛盾の最終分類。
- 同一人物・同一能力・同一事件に見える記述の統合判断。
- `00_概要.md` の大規模な書き直し。
- 人物の「現在の状況」を最終版として確定すること。
