# 世界観ノート案内

このディレクトリは、『やる夫は退魔師として開眼したようです』の原稿から抽出した設定・人物・時系列・あらすじを用途別に参照するためのノート群です。

## 現在の整理段階

2026-09-17から、**ストーリー全体を読み終える前でも安全にできる整理**を先行しています。

この段階では、既存ノートにある情報・引用・出典・「提供者の指摘」を削除しません。また、伏線か矛盾か、どの情報が重要か、どの重複が不要かといった作品全体の理解を要する判断は保留します。

巨大化した旧ファイルは保全し、今後の追記先を分割することで、これ以上の肥大化を止めます。全編確認後に旧ファイルと新ファイルを照合して正式統合します。

## まず見る場所

- `00_概要.md` — 世界の仕組み・勢力・主要状況。旧運用の話別記録も大量に残るため、全編確認前は大規模編集しない。
- `06_あらすじ.md` — **今後の各話・各章の物語進行専用**。
- `01_用語集.md` — 旧用語集。既存情報の保全用として凍結。
- `01_用語集/` — **2026-09-17以降の新規用語追記先**。基本原理／組織・役職／術・呪具／妖魔／固有名詞に分割。
- `02_人物/` — 人物情報。現状は陣営別巨大ファイル。`02_人物/README.md` に整理方針あり。
- `03_地理.md` — 場所・地名。
- `04_歴史・年表.md` — 旧年表本文。内容を保全。
- `04_年表/README.md` — 年表を丸ごと読まず、必要部分だけ読むための行範囲索引。
- `05_社会・制度.md` — 組織、文化、制度、技術、魔法体系など。
- `99_未確定・矛盾メモ.md` — 旧未確定メモ。既存情報の保全用として凍結。
- `99_未確定/` — **2026-09-17以降の新規追記先**。未回収の伏線／矛盾・要注意／解決済み／話者表記に分割。

## 新しい情報の置き場所

- 物語が「何が起きたか」 → `06_あらすじ.md`
- 世界全体の仕組み・勢力図・大きな現在地 → `00_概要.md`
- 用語 → `01_用語集/` の該当分類
- 人物 → `02_人物/`
- 場所 → `03_地理.md`
- 年代・事件順 → `04_歴史・年表.md`（参照は `04_年表/README.md` の範囲索引を使用）
- 制度・社会・組織運用 → `05_社会・制度.md`
- 未回収・矛盾候補・解決・話者判定 → `99_未確定/` の該当分類

複数ファイルに関係する情報でも、長い引用や詳細は原則一か所に置き、他方は短い参照にします。ただし、**既存の重複は全編確認が終わるまで削除しません**。

## 安全整理でしてよいこと

- 案内・索引を作る。
- 今後の保存先を分割する。
- 必要部分だけ読める行範囲を記録する。
- 明らかに機械的に判定できる分類を行う。
- 元情報を残したまま参照性を上げる。

## 全編確認後まで保留すること

- 既存記述の削除・大幅圧縮。
- 「重要ではない」「重複だから不要」という判断。
- 伏線と矛盾の最終分類。
- 同一人物・同一能力・同一事件に見える記述の統合判断。
- `00_概要.md` の本格的な書き直し。
- 人物の「現在の状況」の最終確定。
