## 新しい情報の置き場所

- 物語が「何が起きたか」 → `06_あらすじ.md`
- 世界全体の仕組み・勢力図・大きな現在地 → `00_概要.md`
- 用語 → `01_用語集/` の該当分類
- 人物 → `02_人物/`
- 場所 → `03_地理.md`
- 年代・事件順 → `04_歴史・年表.md`（参照は `04_年表/README.md` の範囲索引を使用）
- 制度・社会・組織運用 → `05_社会・制度.md`
- 未回収・矛盾候補・解決・話者判定 → `99_未確定/` の該当分類

複数ファイルに関係する情報でも、長い引用や詳細は原則一か所に置き、他方は短い参照にします。ただし、**既存の重複は全編確認が終わるまで削除しません**。

## 安全整理でしてよいこと

- 案内・索引を作る。
- 今後の保存先を分割する。
- 必要部分だけ読める行範囲を記録する。
- 明らかに機械的に判定できる分類を行う。
- 元情報を残したまま参照性を上げる。

## 全編確認後まで保留すること

- 既存記述の削除・大幅圧縮。
- 「重要ではない」「重複だから不要」という判断。
- 伏線と矛盾の最終分類。
- 同一人物・同一能力・同一事件に見える記述の統合判断。
- `00_概要.md` の本格的な書き直し。
- 人物の「現在の状況」の最終確定。
