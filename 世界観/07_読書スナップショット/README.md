# 読書スナップショット

このディレクトリは、作品を読み進めた**その時点の理解・印象・未回収事項**を固定するための記録です。

## 目的

作品全体が長いため、全編を読み終えた時点の記憶だけで整理すると、序盤・中盤の情報や当時の人物の見え方が終盤の情報に上書きされやすい。その対策として、原則5話ごとにスナップショットを保存します。

## 重要ルール

- 各ファイルは、その範囲までを読んだ時点の理解として保存する。
- 後の話で真相が判明しても、古いスナップショットを「間違い」として書き換えない。
- 後から判明した内容は、次のスナップショット側で「以前はこう見えたが、ここでこう判明」と記録する。
- 事実・推測・第一印象をできるだけ区別する。
- 最終的な設定整理は、全編確認後に各スナップショットを再参照して行う。

## 参照順

現収録分001〜119は一通り読了済み。以後、世界観整理・人物整理・感想・全体分析を行う時は、**最後まで読んだ記憶だけに頼らず、次の順で参照する。**

1. まず `統合/` の部・章単位スナップショットを読む。
2. 詳細が必要な区間だけ、5話単位スナップショットへ戻る。
3. 台詞・レス番号・AA描写・正確な表現が必要な場合だけ `原稿/` を読む。

この三段階により、毎回001〜119を一気読みして終盤へ記憶が偏ることを防ぐ。

統合ファイルは5話スナップショットの代替ではない。**「全体を思い出す入口」**として使い、細部・初見時の見え方・未確定事項は元の5話ファイルを優先する。

5. 未回収・気になる点
6. この時点での作品の印象・テーマ
7. 後から上書きしない方がよい初見情報
