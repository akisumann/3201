# 読書スナップショット

このディレクトリは、作品を読み進めた**その時点の理解・印象・未回収事項**を固定するための記録です。

## 目的

作品全体が長いため、全編を読み終えた時点の記憶だけで整理すると、序盤・中盤の情報や当時の人物の見え方が終盤の情報に上書きされやすい。その対策として、原則5話ごとにスナップショットを保存します。

## 重要ルール

- 各ファイルは、その範囲までを読んだ時点の理解として保存する。
- 後の話で真相が判明しても、古いスナップショットを「間違い」として書き換えない。
- 後から判明した内容は、次のスナップショット側で「以前はこう見えたが、ここでこう判明」と記録する。
- 事実・推測・第一印象をできるだけ区別する。
- 最終的な設定整理は、全編確認後に各スナップショットを再参照して行う。

## 1バッチの基本構成

1. その範囲の物語の流れ
2. 人物の現在の見え方
3. 関係性の変化
4. 世界設定として新しく分かったこと
5. 未回収・気になる点
6. この時点での作品の印象・テーマ
7. 後から上書きしない方がよい初見情報

## ファイル

- `001-005.md` — 予告・第1話〜第5話時点
- `006-010.md` — 第6話〜第10話時点
