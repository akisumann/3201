# 原稿110 読書スナップショット

対象: `110_第4部第8話.txt`（第4部第8話／原文第2部第58話／第5章「清く正しい選挙 編」）

## 1. やる夫とできる夫の正面衝突

- やる夫は筋力・俊敏性・硬度・柔軟性・動体視力・反射神経を重ねて強化し、できる夫と近接戦闘を行う。
- できる夫も身体強化と聖書由来の術で対抗する。祈りによって剣を生み、やる夫と同等の速度へ達し、蜂の巣状の防護結界で追尾弾を防ぐ。
- やる夫が怒っているのは過去のいじめではなく、できる夫が家族であるつかさたちへ手を出したこと。できる夫は座敷童子を家族と呼ぶやる夫を「神の敵」「殺すべき怨敵」と認定する（110 #703-758）。

## 2. 悪意を排除する空間ルール

- ナギを守るため以前の立ち入り禁止を解除しており、できる夫に接近を許したやる夫は一度焦る。焦ると能力をすべて使用できなくなるが、できる夫が攻め切らない間に落ち着きを取り戻す。
- やる夫は「できる夫は自分へ近づけない」と再設定し、続いて「やる夫に悪意を持つ全ての存在は部屋に入れない」へ対象条件を修正する。
- 悪意を持たないナギは領域へ入れる一方、できる夫本人と攻撃は完全に遮断される。できる夫の祈りによる対抗術も突破できない。
- やる夫は決着よりナギの避難を優先し、できる夫を無視して移動しようとする（110 #759-795）。

## 3. できない夫の奇襲と能力の穴

- できない夫が建物を崩し、巨大な瓦礫をやる夫とナギへ落とす。「怨みは無いけど死んでくれ。オレのために」と語る。
- 敵意のない無機物自体は「悪意を持つ存在」の排除条件に該当せず、瓦礫が領域へ入る。
- やる夫は自分とナギ以外の全てを排除しようとするが、それでは地面や酸素まで消えると気付き、さらに焦ったことで発動中の効果をすべて失う。
- ビル倒壊はできる夫の作戦だった。できる夫は祈りで自分だけ安全な場所へ退避し、事情を知らされていなかったできない夫は取り残されて激怒する（110 #797-818）。

## 4. キョン子製防護呪符

- やる夫とナギは、事前にキョン子が作った防護呪符でビル崩落を生き延びる。キョン子本人が現場にいるわけではない。
- ナギへ渡されていた十枚のうち九枚が焼失し、残りは一枚。やる夫は自分には不要として最後の一枚をナギに持たせる。
- 直後はやる夫への攻撃が通り、できない夫がナギ確保へ向かう。できる夫は勝利を確信する（110 #820-839）。

## 5. やらない夫の参戦

- できない夫がナギへ迫ったところで、やらない夫が現れる。
- 一気に間合いを詰めてできない夫を吹き飛ばし、倒れたやる夫の前に立つ。
- やる夫へ立つよう促し、できる夫・できない夫へ「10年越しの同窓会」と告げて戦闘へ入る（110 #840-850）。

## 現在地点

- やる夫は焦燥で空間ルールを含む効果を失い、攻撃を受けて倒れているが、生死に関わる状態とは示されない。
- ナギは防護呪符を一枚所持。できない夫に確保される直前、やらない夫が介入した。
- やらない夫が閉鎖都市へ侵入していたことが確定し、できる夫・できない夫との「10年越しの同窓会」が始まる。
- できない夫の参加理由、できる夫との現在の関係、ナギを「頂いて行く」目的は不明。
- できる夫はやる夫の能力を言霊の亜種と仮定するが、追加検証が必要として断定していない。
