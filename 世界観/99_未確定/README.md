# 未確定・矛盾メモ 分割追記先

旧来の `../99_未確定・矛盾メモ.md` は既存情報の保全用として当面凍結する。
全編を読み終える前に、旧項目を「伏線」「矛盾」と最終判定して移動することはしない。

2026-09-17以降の新規事項は、判断できる範囲で以下へ記録する。

- `00_未回収の伏線.md` — 作中で答えが後に出そうな問い、明示的に保留された謎
- `01_矛盾・要注意.md` — 記述同士の食い違い、時系列・設定上の注意。伏線の可能性がある場合は断定しない
- `02_解決済み.md` — 後の原稿または提供者の指摘で答えが確定した事項
- `03_話者表記.md` — AA→意味文変換での話者ラベルのずれ、判定注意

## 運用

1. 同じ事項が旧 `99_未確定・矛盾メモ.md` にある場合、旧本文は削除せず、新ファイル側に「旧99の項目への追記」として記録する。
2. 伏線か矛盾か判断できなければ `01_矛盾・要注意.md` に「分類保留」として置くか、旧99に手を付けず保留する。
3. 解決した事項は新しい `02_解決済み.md` に答えと根拠を記録する。旧99の打ち消し処理は全編確認後にまとめて行う。
4. 全編確認後、旧99を照合して4分類へ正式移行する。
