# 人物:「組織」(陰陽寮の敵対組織)

トップ=死神(夜神月)、大幹部、地方幹部、その関係者。所属が確定していない妖魔(エト)もここに置き、注記する。

## トップ・大幹部

- **死神 / 夜神月**(組織のトップ)
  - **第30話(初戦闘)**:「座敷童子の繋がりを絶ち、誘拐できる奴は限られているし、もう時間が無いから僕自ら来た」「球磨川の奴、いよいよ調子に乗り始めたな! こんな肉体労働を僕にさせるとは!」(=球磨川の指示で動いている)。最初の一手でつかさとやる夫の繋がりを「殺し」、飛ぶ斬撃でやる夫を殺したつもりが生存(「能力がレジストされた?」)。「僕は戦闘が苦手なんだぞ!?」「僕は非戦闘員だ!」。やる夫の言霊で一瞬止まり「僕は死神だ。全てを『殺す』」「一歩でも僕の領域に入ってしまえば存在ごと殺す。力の差など関係ない」。黒の攻撃を殺して「やはり僕の能力は最強だッ!!」、直後に新城が領域に入って「どうして死なない!?」。「ネウロぉお! 僕達を守れぇ!」とつかさを連れて撤退。作者「死神の行動は何故か一々ギャグになる」「彼は力は強いんですよ? 力は」。読者「劣勢でもギャグで処理できる月さんはやはり最強」。出典:030 #446-597
  - 第20話で人格が判明。一人称「僕」。「全人類への妖魔の周知」を理念に「何十年かけて準備してきた」。「後は数人の座敷童子と、もう僅かなエネルギーさえあれば可能だ」。大幹部という名称を気に入り「盛大に格好付けたい」が、誰も命令を聞かず「この組織はもうダメだ!」と嘆く。ネウロに常に煽られる。真の目的を知る地方幹部が竜崎の指示で捕縛されかけたこと、陰陽寮の勢力回復、「今のペースなら目標まで後10年」から「力の拮抗している今、ここで仕掛けるしかない。**全面戦争だ**」と決断。陰陽寮側(竜崎)は「夜神月」と呼び「効率最優先、嬉々と女性・子供を使う」と評する(同一人物 ○。読者「月さん芸人過ぎてワロタ」)。「テレビとかハイカラな文化は分からない」。出典:006 / 019 / 020 #2849-2884

- **魔人ネウロ**(組織の大幹部・Aランク)
  - **第27話**:伊藤誠に「組織」の後ろ盾を約束していた(阿修羅は「組織から借り受けたB級妖魔」)が、誠が呼んでも来なかった(「ネウロあの野郎、俺を騙しやがったな!?」)。番外編ではメタ乱入で「次は我が輩を呼び出しだ!」。出典:027 #991-996, 新スレ #52 / 番外 #225
  - **第30話**:月の救援に登場「キサマ、我が輩の楽しみを邪魔するんじゃぁない!!」。新城「組織の大幹部クラスがまた一人来た」。月に「まったく、貴様はどうしようもない奴だな」「お前達二人は先に帰っていろ。で、我が輩は……どうやって逃げような?」。作者「ネウロが出てきたからね。しょうがないね」(月が逃げ切れた理由)。出典:030 #552, #585-587
  - 第6話の会合で「面白くなってきたぞ、我が輩こういうの大好きだ」と働かず死神と険悪だった妖魔。第18〜19話で2chトンネル地下の儀式場に現れ、ジャギに「組織の大幹部が一人、魔人ネウロ」と識別された
  - 性格:一人称「我が輩」。娯楽本位。「全力を振り絞る死闘! 震える心! 高ぶる闘志! ……は、どうでもいい」。やる夫を「驚くほど醜悪、本当に人間か? 海難法師に違いない」と揶揄。ゼロの「白饅頭は俺の獲物」という約束を「テキトーに相槌した気がする」程度に覚えていて一応守り、人造妖魔を試運転としてぶつけて観戦。「白饅頭以外にも良い奴がいる(やらない夫)」
  - 能力:反逆した人造妖魔(Bランク相当・バリア持ち)を「少し撫でただけで」殺した。「アイツがその気なら、誰もこの場には居なかった」(ジャギ)
  - 儀式:日本中の畏れを集めて人造妖魔を製造。上司格に「捕獲しろよ、もったいない」と叱られる
  - 別れ際:「また会うかもしれんな。その時は我が輩が手ずから相手してやろう。楽しみにしているぞ人間!」
  - 出典:006 #940-942 / 018 / 019

- **組織側の人物(ネウロの上司格)**:人造妖魔を殺したネウロに「馬鹿かお前。捕獲しろよ、捕獲。もったいない」。死神か別人かは不明。出典:019 #2711

- **ねこまた(大幹部)**:組織の大幹部。語尾「〜ニャ」、一人称「ボク」。球磨川に「ピトーちゃん」と呼ばれる。ゼロの昇格に「地方幹部の中ですら最弱の雑魚をボクと同格とか嫌」と反対。会議を「漫才」と切って帰る。内心「せっかく来てくれた数少ないまともな大幹部が帰っていく。やはり死神は馬鹿か」。出典:020 #2867-2875

- **ルルーシュ・ランペルージ / ゼロ**
  - **第20話:第2章の事件の立案者**。心霊番組の一斉放送で死神が数十年かけて集めたエネルギーを一回で凌駕し、「約束どおり」組織の**大幹部に昇格**。被害者を重犯罪者に限り、一般人の被害を抑え、陰陽寮の準備を待つように時間差をつけた(竜崎はこれを「夜神月の策ではない」と見抜いた)。組織の真の目的「全人類への妖魔の周知」の理念に惹かれて加入したが「本当に可能なのか?」と疑い、座敷童子が必要と聞いて「なに?」と反応。仮面をつけている(死神「その仮面は飾りか」)。「俺はこんな組織にいていいのか?」。ねこまたに「地方幹部の中ですら最弱」と言われる
  - **第24話**:志々雄の敗北直後に本人が現れ「諸君! 私がゼロだ!」「今日は私の部下が世話になった、その礼と挨拶に来た」。やる夫に「ルルーシュぅうう! 帰れぇ!」と言われ「ルルーシュなるイケメンは知らん」「一応、俺はお前らの恩人……」。志々雄に「私の予知ではお前は死んでいた! 助かったのは私が介入し助けたからに過ぎない」。「私は私の目的の為に今も歩み続けている」「貴様も、守りたい者を守るのだろう!? ならば早く強くなれ」「あの時のお前の咆哮は本物だった!」「早く上って来い! 『敵』は待ってはくれんぞ!」。追撃せず志々雄を連れ帰る(やらない夫「お優しいんだか、なんなんだか」)。志々雄は「大幹部様」と呼び、ゼロも「今、大幹部って……そうだ」と受けた=第20話時点で大幹部に昇格済みの呼称と整合。**「予知」=件(くだん)の能力(○)。「恩人」の意味、ゼロの「目的」「敵」が誰かは未確定**。出典:024 #562-571
  - 種族:**件(くだん)**。予言をしても死なない
  - 立場:組織の**地方幹部**(自称「下働き」はプライドの高さゆえ「トップ以外すべて下働き」)。組織内では「ゼロ」。「実力が無い俺でも成り上がることは可能」と自覚
  - 街中で戦わなかった理由:町に東北の地区長(新城)が来ていたため「私闘に巻き込む必要はない」
  - 決意:「待ってろよ、白饅頭! 必ず見返してやる」
  - 第10話:カフェで三人と「仲直りの食事会」。つかさに一般人が感知できるお札を渡した。やる夫が退魔師3週間目と知り「赤子同然のルーキーに俺が負け」と衝撃。ランク制度を詳しく解説(自分のランクは「敵に言うはず無い」)。「人間の敵は人間だ」。別れ際に**忠告「後悔したくなければ、今日一日、絶対につかさを一人にさせるな」**。東京滞在を今日まで延長していた。C.C.に「友達でも助けに行ったのか」とからかわれる
  - 第9話:東京の街中でつかさと「偶然」再会し、再び食事に誘う(2度目の失敗)。「妖魔でも普通の人に認識させる方法はある」。つかさが「アカギと会った」と言うと驚くが、「あんな白饅頭が地区長のアカギと知り合いな訳ない」と誤解。妹の名は**ナナリー**。「こんなのに負けるようでは組織でも成り上がれない」
  - 出典:005 / 006 #833-856, #937-948 / 009 #1307-1322

- **C.C.**:ルルーシュと行動する妖魔。一人称「私」。ピザが好き。ルルーシュの行動を見透かしてからかう。組織との関係は不明。出典:010 #1453-1462

- **球磨川**:5年前、かがみとつかさを襲った妖魔。『』の台詞。人の幸福を壊すのが目的。第14話で**「組織」のAランク妖魔**と判明。「可愛い子を捕まえて来い」と命令されており、かがみと組んでつかさの屋敷へ来た。「最近はどこに行っても可愛い子ちゃんを見なくなった。僕、頑張りすぎちゃった?」=座敷童子減少の実行犯の一人(○)。新城の奇襲で30秒で敗北し「かがみちゃん助けて」。出典:012 / 014 #2038-2084
  - **第30話**:月に「こんな肉体労働」=つかさ誘拐を命じた(月「球磨川の奴、いよいよ調子に乗り始めたな」)。組織内で球磨川がトップの月に命令できる立場になっている(○)。出典:030 #447

## 地方幹部・実行役

- **地方幹部たち(第20話の会議)**:「ウゼェから反対、もう帰っていいですかァ」の男、「火火火、おじさん」、「昔からこの組織は頭脳担当が少なすぎる」と賛成する者、「勤勉ですか!? 怠惰でなければ最高デス!」の者、「あまめはぎ」、件のゼロを「解剖させて」と言う女性、「幹部とか興味ない」者、「迷い船」、「お嬢様の代理出席」の者、「あぎょうさん」。半数以上の大幹部は欠席。出典:020 #2867-2870
- **レミリア・スカーレット**(組織の大幹部→脱退):「世界のどこか」の巨大な城の城主、吸血鬼。アーカードを「おじいさま」と呼ぶ(「家族でそういうの良くないわ」「可愛い孫娘のちょっとした我侭」)。人材コレクターで、やる夫の話を聞き「私の眷属になれば永遠の命よ」と欲しがるがアーカードに「あいつは人間だ。それとも私とやり合うか?」と止められ、「キョン子ちゃんの伴侶なら略奪はだめね」。**「誘われたからとりあえず入ったけど全部咲夜に任せてた。大幹部とかいう謎の役職に付かされて仕事やらされかけた。飽きたし、もう止めるわ」と組織脱退**。Dランクを「聞いたことない」。「人間は全部早いわ。生誕も成長も老いも終わりも」。作者「チラッと咲夜さん出してたし、レミリアともくっつけちゃえ」。出典:028 #108-133, #213
- **十六夜咲夜**:レミリアのメイド。組織との連絡を全て任されていた。組織の動向報告:藍染による目的漏洩と幹部死亡、中部支部強襲と藍染の死。出典:028 #132-135
- **組織幹部(第30話、名前未確定)**:月の救援に来た「組織側の強敵」。黒を「噂の『黒の死神』」と呼び、鎖付き武器の包囲を突破して高速戦闘。「貴様も、素晴らしいな」。原稿の注記どおり固有名は断定不可(△:ねこまた/ピトーか、球磨川か、未登場の幹部か)。出典:030 #562-582
- **阿修羅**(B級妖魔、組織から誠に貸与):伊藤誠が「適当な村に放って」5年前にキョンとハルヒを正面から食い殺した妖魔(「あいつ等は強かった! 俺も誠の援護が無ければ負けていた」)。第27話で誠に召喚され、キョン子を「美味そうだ」と狙うがアーカードに一撃で殺された。出典:027 #958-975, #982-987, 新スレ #52

- **志々雄真実**(ししお まこと)= **C級妖魔「トンカラトン」**(第24話で正体・フルネーム判明)
  - 第21話ラストの路地裏の「謎の男」(○)。全身に包帯を巻いた男。**組織の地方幹部**(エトが「組織の地方幹部ともあろうお方」)。刀使いで銃弾を全て切り落とし、剣まで斬る。炎を纏う秘剣を持つ。「所詮この世は弱肉強食」。キョン子の呪具を「穏便に」奪おうとした(戦闘で呪具を消費したくない)。やる夫の実弾が当たることに「どういうことだ?」。「決戦は間近だしな。ここらで少し退魔師を減らしておこう」「あの腹立たしい白饅頭に加勢が行くなど認められるか」とやらない夫を足止め。公園の子供惨殺の犯人ではない。出典:021 #6-9 / 022 #146-168 / 023

- **御宅**(おたく)
- **伊藤誠**(いとう まこと、死亡):退魔師・式神使い。5年前、キョン(キョン子の父)とコンビを組んでいたが、目的は「最強の式神」=安倍晴明の十二天将。「安部清明に連なる家系」の噂を追ってキョンに媚びて取り入り、十二天将を出させるため「組織から借り受けたB級妖魔」阿修羅を村に放ち、退魔に来たキョンとハルヒを援護付きで殺させた(「俺はキョンを殺す気は無かったんだ! 十二天将を出させるだけのつもりで!」「俺は悪くねぇっ!」)。葬儀直後に消えたキョン子を5年探し、「罪悪感に苛まれる好青年」を演じて接近するがキョン子に見抜かれる。式神・紅美鈴(3億円で購入)に「全力でキョン子を捕縛しろ」「殺せ」。「呪具師相手には準備が出来てない奇襲が一番楽」。やる夫を「2流退魔師」「白饅頭」。アーカード出現で「組織のみなさーん! 大幹部のネウロさ〜ん?」と呼ぶが誰も来ず逃走。逃走中に「座敷童子の情報を組織に売って、より強い妖魔を借りる。アーカードは俺のモノ」「俺は世界最強になるんだ」→**のび太に眉間を狙撃され即死**。遺体は新城が回収、キョン子が事前に呪毒で脳と魂を汚染し情報漏洩を防いだ。読者「やっぱ誠はクズが似合う」。出典:026 #755-848 / 027 #892-996, 新スレ #3-11, #50-61 / 028 #147
  - 心霊番組の無許可放送の「主犯」。「二次元の嫁を式神で作る会」の会員で、人造妖魔で嫁を作るために金でディレクターを釣った。会から捨て駒にされ、集合場所も連絡先も全て虚偽だった。覚の調書で洗脳も催眠もなしと確認。麻呂に「打ち首」「斬首」と言われ続ける。出典:020 #2800-2819

## 所属未確定

- **エト**= **喰種**(第24話で正体判明)
  - 公園の子供惨殺の**真犯人**。全身包帯の女。「くすくす」「ケタケタ」と笑う。上空から降下し「同じ包帯仲間としてアナタに味方してあげる」と志々雄に絡む。やる夫に撃たれて「屠殺よ。家畜は死ね」と**街より大きい巨体(赫者)に変貌**、ジャギの配下を一撃で全滅させやる夫を踏み潰した。恐怖を与えるほど付け上がり、甚振るために近づく性質。子供殺しは「覚えてないなぁ……でも、だからどうした?」。やる夫の言霊で拘束され「こんな拘束程度……ッ!」。組織との関係は不明。出典:023 #218-260
