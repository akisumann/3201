# 人物:「組織」(陰陽寮の敵対組織)

トップ=死神(夜神月)、大幹部、地方幹部、その関係者。所属が確定していない妖魔(エト)もここに置き、注記する。

  - **第32話(「組織側の男」として)**:警報に「侵入者か!? まさか地下か!? 今すぐ戦力を座敷童子の守りに固めろ!」。座敷童子を本拠地でなく遠野に置いた理由「ここと本拠地の防御で戦力を二つに分けなきゃいけない。そんな怖いことできるか!」。「地下へは僕と、唯一信頼できる大幹部のピトーで行く」「各地に散っていた地方幹部を転移で召集しろ! これで大発生は生じる計算だ」「妖魔の世界で、人間はどれだけ抗えるかな?」。出典:032 #782-793
  - **第33話(vs やる夫、決着せず)**:牢屋でやる夫と再戦。「あの時、僕に手も足も出なかった事を忘れたのかな?」「男らしく死ね!!」。やる夫が領域に入ると「貴様程度の奴が僕の領域に侵入できる筈がない!」「ちょっと前に新城が普通に踏み込んでた気がするが……やっぱり気のせい! 僕は無敵!」→「え!? お前も入れるの?」。出典:033 #874-893
  - **第36〜37話(敗北と消滅)**:「なぜ僕の領域が破られる!? この世には矛盾した能力もありふれている。全てを破壊する能力と絶対壊れない能力など。基本的により力の強いものが勝つ」「僕の体には今、世界を変革させる程のエネルギーが内包されている! 何十年と集めてきた力だぞ!?」。エネルギーが目標に達し「世界を変えるに足るカードが揃った!」→座敷童子の正体を嬉々として解説(→用語集)。ゼロの裏切りで「この数十年の努力、全てが水泡に帰した!!」「殺す……お前らだけは、絶対に殺す」と全エネルギーを取り込み「僕は今、この世界で最強になった」。ゼロ「動きが単調過ぎて、攻撃する場所、タイミングさえ読めれば何てこと無い雑魚妖魔だ」「私は大の戦闘弱者だが、貴様はそれ以上か!」。かがみの斬撃に「ひぃいい! 卑怯だろぉ!」「そうだった、僕には鉄壁の防御が」。つかさの願いで攻撃がやる夫を避け「僕の能力が無効化された?」、ゼロ「お前が相手しているモノはこの世界そのものだ」→存在ごと消され「分かった! 僕が悪かった! もうしない! 今後一生、誰とも戦わない!」「誰か僕を助けろぉお!」「僕は死に」。出典:036 #606-702 / 037 #939-#35
  - **最終話(生還)**:「僕はまだ生きていて良いのか!? やはり僕は世界に必要とされていたんだ! 新世界の神となる!」→ネウロ「違うぞ死神。つかさの願いは『自分の知っている人が誰も傷つかないこと』。それは貴様とて例外ではない。世界が一時的に貴様を消していただけだ」。組織壊滅を聞き「止めよう! 僕が新世界の神になる計画は中止だ! 全て諦める! 戦闘って、怖いんだな……僕はもう誰とも戦わないぞ。死にたくない」「僕は姿を眩ます! もし生きていたのが陰陽寮にばれたら狙われる!」→「『夜神ライト親衛隊』の設立をしよう! 隊の最大目標は僕を守ること!」「ネウロ、お前が記念すべき親衛隊№1だ! 会長を頼む!」(ネウロ「そのファンクラブ今すぐ止めていいか?」)。原稿では「夜神ライト」表記。出典:040 #737-752
  - **番外5おまけ「暗躍する者」(047 #709-727)**:現在は**妖魔アイドル『夜神ライト』**。「若い女性妖魔を中心に爆発的人気」。ブロマイド『UR「企むライト」』を配り、氷麗を「僕の甘いマスクで一発KO」。「親衛隊は100人を超えた! B級妖魔が入隊するのは初めてだ! 組織で言えば、地方幹部の上位レベル!」。東京でライブ予定、「今の僕達の目標は武道館ライブ開催だ!」「僕は世界を取る!」。ネウロ「本当に貴様はどこを目指しているんだ?」月「それは、僕も聞きたい。でも、死にたくないし、ファンが僕を求めてるんだからな」。
  - **第30話(初戦闘)**:「座敷童子の繋がりを絶ち、誘拐できる奴は限られているし、もう時間が無いから僕自ら来た」「球磨川の奴、いよいよ調子に乗り始めたな! こんな肉体労働を僕にさせるとは!」(=球磨川の指示で動いている)。最初の一手でつかさとやる夫の繋がりを「殺し」、飛ぶ斬撃でやる夫を殺したつもりが生存(「能力がレジストされた?」)。「僕は戦闘が苦手なんだぞ!?」「僕は非戦闘員だ!」。やる夫の言霊で一瞬止まり「僕は死神だ。全てを『殺す』」「一歩でも僕の領域に入ってしまえば存在ごと殺す。力の差など関係ない」。黒の攻撃を殺して「やはり僕の能力は最強だッ!!」、直後に新城が領域に入って「どうして死なない!?」。「ネウロぉお! 僕達を守れぇ!」とつかさを連れて撤退。作者「死神の行動は何故か一々ギャグになる」「彼は力は強いんですよ? 力は」。読者「劣勢でもギャグで処理できる月さんはやはり最強」。出典:030 #446-597
  - 第20話で人格が判明。一人称「僕」。「全人類への妖魔の周知」を理念に「何十年かけて準備してきた」。「後は数人の座敷童子と、もう僅かなエネルギーさえあれば可能だ」。大幹部という名称を気に入り「盛大に格好付けたい」が、誰も命令を聞かず「この組織はもうダメだ!」と嘆く。ネウロに常に煽られる。真の目的を知る地方幹部が竜崎の指示で捕縛されかけたこと、陰陽寮の勢力回復、「今のペースなら目標まで後10年」から「力の拮抗している今、ここで仕掛けるしかない。**全面戦争だ**」と決断。陰陽寮側(竜崎)は「夜神月」と呼び「効率最優先、嬉々と女性・子供を使う」と評する(同一人物 ○。読者「月さん芸人過ぎてワロタ」)。「テレビとかハイカラな文化は分からない」。出典:006 / 019 / 020 #2849-2884
