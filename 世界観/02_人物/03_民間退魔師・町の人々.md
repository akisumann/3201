# 人物:民間退魔師・呪具師・町の人々

陰陽寮にも組織にも属さない人間側の人物。

## 呪具師

- **キョン子**:新進気鋭の呪具師。第21話でやる夫に認識呪具を売り、第22話で糸色望に雇われる。第23話で志々雄に呪具を要求され「私のカネは、私の命より遥かに重い!!」と拒否、やる夫に救われ「後は任せた」と逃走。**第24話**:実は「自宅まで予備の呪具を取りに」戻っただけで再合流(「私が恩人を捨てて逃げる訳無いだろう、退魔師じゃないんだから」)。エトを喰種と看破し赫包の弱点を説明、翼で逃げようとするエトを大量の呪具で牽制(「人喰い妖魔がこの世で二番目に嫌い」「早く飛べよ! 害虫らしく!」)。志々雄戦では「勝ち目が無い」と再び姿を消し、実は治療呪具を取りに戻ってトンカラトン化した3人を治療。「私はお前らになんか借りは作らない」「退魔師とはビジネスライクな関係でさえ嫌」「私は退魔師とコンビは組まない、そう決めてる」「ネットを主な活動場所にしてるのもその所為」「私の知ってる退魔師とかいうクズは、そんな奴等じゃないだろう!?」。「退魔師は嫌いなんだ、だって……」に志々雄が「信じれば、裏切られる……か?」と続けた=**キョン子は過去に退魔師に裏切られた(○)**。**第25話**:損失は最終的に**1億円突破**(代用の治療呪具が1個2500万円以上×3人)。陰陽寮も払えず依頼料では賄えず、糸色望が「力の篭ってない術式」を大量に買い取ってくれなければ破産だった。やる夫を「疫病神」と呼び号泣。「体で働いて返せ」=力の篭っていない術式にやる夫の力を籠めさせる→炎上。「コイツ、一瞬で数千万クラスの力を籠めやがったな」と見て**取引**を提案:術式提供/力提供/呪具は山分け。「これはただの協力関係。本当のコンビてのはもっと互いに命を預けて信頼しあうような……ま、そんな関係、私が作れるわけ無いがな」「危なくなれば即座に切り捨てる。互いに期待するなよ」。やる夫の「絶対に仲間を見捨てない」「キョン子も仲間」に「気持ち悪いなぁ。ま、でも期待しないで、その時を待ってるよ」。**何者かがキョン子の法力を辿って2ch町に迫っている**。読者「キョン子に幸あれ」。出典:015 / 017 / 021-023 / 024 #346-353, #377-381, #384, #394-404, #545-560 / 025 #634-666, #702
  - **第26話**:さやか・まどかの高校(担任・黒井ななこ)に転校。本名を隠すため名簿を「キョン子」だけにし、教室全体に「私の事を気にしなくなる程度の暗示」をかける(さやか・まどかはレジストできる)。「高卒の資格ぐらい取っておこうと思っただけ」「利害関係のない退魔師なんて関わるだけ不愉快」。治癒呪具を「クラスメイト割で1個100万」(通常最低300万)。「金づるになるかもしれない人間相手には営業スマイルを見せる」。「カネは誰も裏切らないからな」。やる夫が親を詮索すると「私の親なんて、放っておけよ! もう居ねぇよ! あんな馬鹿な奴!」「次に詮索したらコンビとやらも全部解消」と帰る。帰路「本心から心配してくれてる人に怒ってんだよ。そんなんだから今でもずっと一人なんだよ」→「一人なら誰にも期待しないで済む! 失うものも無い!」。伊藤誠と遭遇。**父キョン(呪具師)、母涼宮ハルヒ(呪具師)は5年前に人喰い妖魔の村で死亡、キョン子(当時12歳)が誠に連絡する役だった**。誠の演技を「くっさい演技」「私の両親を殺したのだって、お前だろ?」と看破。攻撃用呪具は2枚しか持っておらず(防御・回復が主力商品)「よゆー」と嘘をつく。出典:026 #714-848
  - **第27話(正体判明)**:回想:葬儀の参列者は「呪具師だけでB級妖魔に立ち向かった馬鹿」「助けに行かなくて良かった」と言う退魔師ばかりで、棺は空。**生まれつき人の感情を読む特技**(「なんとなく良い人間、嫌な奴は分かった」、嘘を「嘘……ではない」と判定できる)があり、参列者の本心が全部聞こえた。「なら退魔師ってなんなんだよ!」「人間の死に貴賎なんか無いだろ!」。新城に「お父さん達を生き返らせることは出来ないんですか!?」→断られ、「結局お前だって自分達に利する事しか考えてない」「もう誰かに裏切られるのはたくさんだ! 私は一人で生きていく! 私が家族を生き返らせる!」。12歳で父に並ぶ呪具師(新城)。現在:「まさか私が誠の言葉に同意する日が来ようとはな」。誠の目的を聞いて「分かっただけでも、ちょっとスッキリした」。「十二天将なんて1000年以上前に解散した」と明かした上で、**アーカード(十二天将の一人)を召喚**して阿修羅を一撃で殺させる。「アーカードを見せていいのは、必ず殺す人間か、本当に信頼する相棒だけ」「キョンは最期、彼を呼ばなかったんじゃない。呼べなかったんだ」(主をキョン子に変えていた)。「私はもう誰も信じない。誰にも期待しない。特に退魔師はダメだ。大ッ嫌いだ」と言いつつ、やる夫には「最後に一回だけ期待してみようかと思ってな」とアーカードを見せた。式の維持で「死にそう」。やる夫を治療し、**本名『―――』を明かす**「誰にも言うなよ! 今はお前以外、誰も知らないんだからな!」。それでも「相棒とか気持ち悪い奴じゃない、ただの協力関係」。アーカードの「子作りしろ」に「お前がどうしてもと言うなら何でも……せめてお前の部屋で」と満更でもない。出典:027 #863-889, #897, #941, #966-979, #988-989, 新スレ #4-49
  - **第28話**:やる夫に呪符作りを教えて家を爆破(「私、人に呪符の作り方を教える才能ないわ」)。内心:「私がやる夫と初めて会った時から、ずっとやる夫を監視してる奴が居る」「たぶん誠を殺したのもソイツ」「護衛っぽい監視の仕方」。誠の死体から情報が抜かれないよう「遠距離から呪毒で脳と魂を汚染しておいた」。自宅は安アパート一部屋、呪具製作の道具で「おっさんの部屋」状態。やる夫に「別に私の家で生活してもいいぞ」「寝る所も私と一緒だけど」。**願望機**(死者蘇生用、5年間製作、何億円もつぎ込んだ)を「想像通りだよ」と説明。つかさ「お金大好きだったのってこのため?」→「自分でも分かんないよ。お金は普通に大好きだし」。やる夫が触れた直後、**両親キョンとハルヒが復活**して呆然。読者「こんなんされたらもうキョン子嫁に行くしかない」。出典:028 #138-178
  - **番外編おまけ「キョン子の野望」**:万札の執念だけを剥がす錬金術を試み赤字。「後日、遥かに便利な『全自動エネルギー製造機やる夫』が手に入り凍結」。出典:番外 #309-319
  - **第30話**:やる夫が「久しぶりにキョン子の家行ってみるか」「家族水入らずの時間はもう終わりでいいかお!?」=第28話以降、両親と暮らしている(○)。出典:030 #454

- **『お昼を一緒に食べてあげる券』の依頼主**:一般人向けにこの呪具を100万円で注文した人物。正体不明。出典:025 #644
- **キョン**(キョン子の父、呪具師、5年前死亡→第28話で復活):安倍晴明の子孫。伊藤誠とコンビを組んでいた(「誠は色々とアレな奴だが、一般人のためには全力で働いてくれるだろ。恐らく」)。「呪具師がいの一番に戦闘に突っ込むな、前衛は退魔師の仕事だろ」と妻を追って村へ行き、阿修羅に殺された。「俺の娘が弱冠12才にして、俺に並ぶ呪具師になった!」と新城に自慢。誠の邪心を知りながら「良心があると信じて」手元に置き、娘を守るためアーカードの主をキョン子に変えていた。新城の客(「常に軍服を着てる変人」と笑っていた)。復活後の第一声「うわ、突然なんだ? 汚ねぇ部屋……」。出典:026 #761-767 / 027 #875-883, 新スレ #5-8 / 028 #176
- **涼宮ハルヒ**(キョン子の母、呪具師、5年前死亡→第28話で復活):人喰い妖魔の報を聞いて「先に一人で行っちゃった」猪突猛進。キョン子の「感情を読むのが上手い」を褒めて育てた。アーカードに「変な指導」をされたらしい。復活後「どこよここ。私、死んだんじゃ無いっけ?」。出典:026 #765 / 027 #867, 新スレ #49 / 028 #176

## 民間退魔師

- **ジャギ**:したらば市周辺の民間退魔師(正規ライセンス未取得、Eランク相当、呪具頼り=銃と高額弾)。「北斗神拳伝承者ジャギさま」を名乗るが銃撃のみ。「俺の名を言ってみろ」は癖(さやか「100回超えた」)。異常な耐久力。さやか・まどかの師匠で「一日でも早く使い物にしなきゃならん」と修行に掛かりきり。**家にはモヒカンの配下(「ヒャッハー! やる夫様のお見えだ!」「お手伝いいたします! やる夫様!」)が多数いる**。やる夫に実弾を裏ルートで手配し、中位依頼のために配下を貸した(さやか「ツンデレ」)。出典:017-019 / 021 / 022
  - **番外編(2〜3章間)**:したらば市に城のような自宅(「建てたのは俺の兄貴。金が有り余って面白半分で、他の兄弟達も乗ってきた」。認識阻害の結界で一般人には普通の家に見える)。「俺の名を言ってみろーっ!」。E級で100〜300万の依頼を銃で受け「おおむね黒字」。ランク別報酬と「妖魔に物理攻撃はとおらん、ハーフなら当たる」を解説。やる夫を「雑魚狩り」と命名。出典:番外 #295-308

- **ジャギの配下(モヒカンたち)**:「ヒャッハー!」「お手伝いいたします! やる夫様!」。やる夫に貸し出され、路地裏で包帯の妖魔に銃弾の雨を浴びせた。出典:022 #121, #130, #148-158
  - 第23話:志々雄相手にフルオート掃射で足止めしたが、エトの巨体の一撃で全滅(観戦者「やる夫の仲間よわ〜い」)

- **美樹さやか**:地元の女子高生。「所詮テレビ番組よ」とトンネルの奥へ入り、透ける異形に追われてまどかを守ろうと素手で殴りかかった。ジャギに救われ、才能が開花。「退魔師とやらに、なってやろうじゃない!」「楽しそうじゃん?」と即決し、ジャギに弟子入り(「あたしは全力でやるからさ」)。「きっと奇跡も、魔法も、あるんだよ」。出典:016-019
  - **第26話**:キョン子の転校先のクラスメイト。ジャギの弟子として「退魔師修行中」(まどか「まだ成ってない」)。キョン子の暗示をレジストして「クラスメイトと担任に変な術掛けてる」と突っ込む。キョン子「あんた等も人間の枠からちょっとずれてる」。治癒呪具の相場(最低300万)を忘れていた。キョン子の営業を「馬鹿?」と拒否して激怒させ、ジャギに愚痴った。出典:026 #714-729

- **鹿目まどか**:さやかの友人。逃走中に転んで「先に行ってて」。才能が開花。ネウロについて「全然怒ってなかった。それどころか楽しそうだった」と観察。「守られるだけって、つらいから」とジャギに弟子入り。出典:016-019

- **坂田銀時**(さかた ぎんとき)
  - 万事屋。ペット探しの依頼で山に来て、やる夫たちの怨霊戦に巻き込まれた。霊視ができ、通販の木刀で「霊体にも有効」な達人級の剣術を振るうが、「怨霊なんて居るわけないでしょ! 人が必死で考えないようにしてんのに」「霊視って何だよ、知るわけねぇじゃん」と一般人を言い張る(幽霊が苦手)。報酬を分けてもらい「退魔師って儲かるのか、ちょっとやってみるか?」。ニンフに「退魔師になったら絞めてやろうか」と睨まれた。黒「白髪」。出典:020 #2751-2772

- **安藤**:正規ライセンス未取得(Fランク相当)の民間退魔師。「3000万円程度」の高額依頼を受付に強要し、妖魔に勝てず違約金1000万円に怯える。友人の入れ知恵で嘘の達成報告を思いつく。出典:011 #1478-1495
  - **番外編(2〜3章間)**:嘘の依頼達成報告をしてかまいたちに四肢切断され(ユーノが治療)、罰としてただ働きでかまいたちのお目付け役に。「別にライセンス無くても仕事請けれるぜ?」と抜け道を解説(→用語集)。「ライセンスって年間維持費に数万円」「何でアイツ(竜崎)が独断で決めたことに従わなきゃいけないんだ」「俺は人に指図されるのが大嫌い」「これは俺の戦いだ!」。糸色「遠い分家とは言え歴史有る退魔師一族出身」。読者「クズだけど割と親切に教えてくれて驚いた」。出典:番外 #234-236, #256-265

- **安藤の友人**:民間退魔師。「物音がする空き家の調査兼退魔」の依頼で嫌な予感がして切り上げ、倒さずに退魔報告をした=第11話の空き家。「終了確認は数十に1つ」と嘘を勧める。出典:011 #1490-1494

- **武器商人**(回想のみ):やる夫に対戦車ロケット弾を調達した人物。「軍隊で実際に使用されている」「縮小魔術が掛かっていて、必要ある場面までキーホルダー程度に縮む」。どこの誰かは不明(△:第16話のジャギ経由の銃調達と同じ筋か)。出典:024 #355-357

## 一般人

- **ディレクター**:金で釣られて無許可放送を指示した一般人。簡単に自白。出典:020 #2796-2797
- **黒井ななこ**:さやか・まどかの担任教師。関西弁。キョン子の名簿の異常に気づくが暗示で「まあええわ」。出典:026 #714-720
- **駅の利用客**:つかさと話すやる夫を「独り言の量が凄まじいな、気持ち悪っ」。出典:番外 #231
- **番外編の依頼人たち**:屋根裏の物音(デパートの祓い屋が暗示で記憶処理)、工事現場の古い壺(現場監督が「絶対に触るな」)、急に死にたくなった人(背後に妖魔)、食欲がない人(ただの風邪)。出典:番外 #288-291
