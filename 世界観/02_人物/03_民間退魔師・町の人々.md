# 人物:民間退魔師・呪具師・町の人々

陰陽寮にも組織にも属さない人間側の人物。

## 呪具師

- **キョン子**:新進気鋭の呪具師。第21話でやる夫に認識呪具を売り、第22話で糸色望に雇われる。第23話で志々雄に呪具を要求され「私のカネは、私の命より遥かに重い!!」と拒否、やる夫に救われ「後は任せた」と逃走。**第24話**:実は「自宅まで予備の呪具を取りに」戻っただけで再合流(「私が恩人を捨てて逃げる訳無いだろう、退魔師じゃないんだから」)。エトを喰種と看破し赫包の弱点を説明、翼で逃げようとするエトを大量の呪具で牽制(「人喰い妖魔がこの世で二番目に嫌い」「早く飛べよ! 害虫らしく!」)。志々雄戦では「勝ち目が無い」と再び姿を消し、実は治療呪具を取りに戻ってトンカラトン化した3人を治療。「私はお前らになんか借りは作らない」「退魔師とはビジネスライクな関係でさえ嫌」「私は退魔師とコンビは組まない、そう決めてる」「ネットを主な活動場所にしてるのもその所為」「私の知ってる退魔師とかいうクズは、そんな奴等じゃないだろう!?」。「退魔師は嫌いなんだ、だって……」に志々雄が「信じれば、裏切られる……か?」と続けた=**キョン子は過去に退魔師に裏切られた(○)**。**第25話**:損失は最終的に**1億円突破**(代用の治療呪具が1個2500万円以上×3人)。陰陽寮も払えず依頼料では賄えず、糸色望が「力の篭ってない術式」を大量に買い取ってくれなければ破産だった。やる夫を「疫病神」と呼び号泣。「体で働いて返せ」=力の篭っていない術式にやる夫の力を籠めさせる→炎上。「コイツ、一瞬で数千万クラスの力を籠めやがったな」と見て**取引**を提案:術式提供/力提供/呪具は山分け。「これはただの協力関係。本当のコンビてのはもっと互いに命を預けて信頼しあうような……ま、そんな関係、私が作れるわけ無いがな」「危なくなれば即座に切り捨てる。互いに期待するなよ」。やる夫の「絶対に仲間を見捨てない」「キョン子も仲間」に「気持ち悪いなぁ。ま、でも期待しないで、その時を待ってるよ」。**何者かがキョン子の法力を辿って2ch町に迫っている**。読者「キョン子に幸あれ」。出典:015 / 017 / 021-023 / 024 #346-353, #377-381, #384, #394-404, #545-560 / 025 #634-666, #702

- **『お昼を一緒に食べてあげる券』の依頼主**:一般人向けにこの呪具を100万円で注文した人物。正体不明。出典:025 #644

## 民間退魔師

- **ジャギ**:したらば市周辺の民間退魔師(正規ライセンス未取得、Eランク相当、呪具頼り=銃と高額弾)。「北斗神拳伝承者ジャギさま」を名乗るが銃撃のみ。「俺の名を言ってみろ」は癖(さやか「100回超えた」)。異常な耐久力。さやか・まどかの師匠で「一日でも早く使い物にしなきゃならん」と修行に掛かりきり。**家にはモヒカンの配下(「ヒャッハー! やる夫様のお見えだ!」「お手伝いいたします! やる夫様!」)が多数いる**。やる夫に実弾を裏ルートで手配し、中位依頼のために配下を貸した(さやか「ツンデレ」)。出典:017-019 / 021 / 022

- **ジャギの配下(モヒカンたち)**:「ヒャッハー!」「お手伝いいたします! やる夫様!」。やる夫に貸し出され、路地裏で包帯の妖魔に銃弾の雨を浴びせた。出典:022 #121, #130, #148-158
  - 第23話:志々雄相手にフルオート掃射で足止めしたが、エトの巨体の一撃で全滅(観戦者「やる夫の仲間よわ〜い」)

- **美樹さやか**:地元の女子高生。「所詮テレビ番組よ」とトンネルの奥へ入り、透ける異形に追われてまどかを守ろうと素手で殴りかかった。ジャギに救われ、才能が開花。「退魔師とやらに、なってやろうじゃない!」「楽しそうじゃん?」と即決し、ジャギに弟子入り(「あたしは全力でやるからさ」)。「きっと奇跡も、魔法も、あるんだよ」。出典:016-019

- **鹿目まどか**:さやかの友人。逃走中に転んで「先に行ってて」。才能が開花。ネウロについて「全然怒ってなかった。それどころか楽しそうだった」と観察。「守られるだけって、つらいから」とジャギに弟子入り。出典:016-019

- **坂田銀時**(さかた ぎんとき)
  - 万事屋。ペット探しの依頼で山に来て、やる夫たちの怨霊戦に巻き込まれた。霊視ができ、通販の木刀で「霊体にも有効」な達人級の剣術を振るうが、「怨霊なんて居るわけないでしょ! 人が必死で考えないようにしてんのに」「霊視って何だよ、知るわけねぇじゃん」と一般人を言い張る(幽霊が苦手)。報酬を分けてもらい「退魔師って儲かるのか、ちょっとやってみるか?」。ニンフに「退魔師になったら絞めてやろうか」と睨まれた。黒「白髪」。出典:020 #2751-2772

- **安藤**:正規ライセンス未取得(Fランク相当)の民間退魔師。「3000万円程度」の高額依頼を受付に強要し、妖魔に勝てず違約金1000万円に怯える。友人の入れ知恵で嘘の達成報告を思いつく。出典:011 #1478-1495

- **安藤の友人**:民間退魔師。「物音がする空き家の調査兼退魔」の依頼で嫌な予感がして切り上げ、倒さずに退魔報告をした=第11話の空き家。「終了確認は数十に1つ」と嘘を勧める。出典:011 #1490-1494

- **武器商人**(回想のみ):やる夫に対戦車ロケット弾を調達した人物。「軍隊で実際に使用されている」「縮小魔術が掛かっていて、必要ある場面までキーホルダー程度に縮む」。どこの誰かは不明(△:第16話のジャギ経由の銃調達と同じ筋か)。出典:024 #355-357
