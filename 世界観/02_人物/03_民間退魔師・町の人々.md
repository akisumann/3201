# 人物:民間退魔師・呪具師・町の人々

陰陽寮にも組織にも属さない人間側の人物。

## 呪具師

- **キョン子**:新進気鋭の呪具師。第21話でやる夫に認識呪具を売り、第22話で糸色望に雇われる。第23話で志々雄に呪具を要求され「私のカネは、私の命より遥かに重い!!」と拒否、やる夫に救われ「後は任せた」と逃走。**第24話**:実は「自宅まで予備の呪具を取りに」戻っただけで再合流(「私が恩人を捨てて逃げる訳無いだろう、退魔師じゃないんだから」)。エトを喰種と看破し赫包の弱点を説明、翼で逃げようとするエトを大量の呪具で牽制(「人喰い妖魔がこの世で二番目に嫌い」「早く飛べよ! 害虫らしく!」)。志々雄戦では「勝ち目が無い」と再び姿を消し、実は治療呪具を取りに戻ってトンカラトン化した3人を治療。「私はお前らになんか借りは作らない」「退魔師とはビジネスライクな関係でさえ嫌」「私は退魔師とコンビは組まない、そう決めてる」「ネットを主な活動場所にしてるのもその所為」「私の知ってる退魔師とかいうクズは、そんな奴等じゃないだろう!?」。「退魔師は嫌いなんだ、だって……」に志々雄が「信じれば、裏切られる……か?」と続けた=**キョン子は過去に退魔師に裏切られた(○)**。**第25話**:損失は最終的に**1億円突破**(代用の治療呪具が1個2500万円以上×3人)。陰陽寮も払えず依頼料では賄えず、糸色望が「力の篭ってない術式」を大量に買い取ってくれなければ破産だった。やる夫を「疫病神」と呼び号泣。「体で働いて返せ」=力の篭っていない術式にやる夫の力を籠めさせる→炎上。「コイツ、一瞬で数千万クラスの力を籠めやがったな」と見て**取引**を提案:術式提供/力提供/呪具は山分け。「これはただの協力関係。本当のコンビてのはもっと互いに命を預けて信頼しあうような……ま、そんな関係、私が作れるわけ無いがな」「危なくなれば即座に切り捨てる。互いに期待するなよ」。やる夫の「絶対に仲間を見捨てない」「キョン子も仲間」に「気持ち悪いなぁ。ま、でも期待しないで、その時を待ってるよ」。**何者かがキョン子の法力を辿って2ch町に迫っている**。読者「キョン子に幸あれ」。出典:015 / 017 / 021-023 / 024 #346-353, #377-381, #384, #394-404, #545-560 / 025 #634-666, #702
  - **第26話**:さやか・まどかの高校(担任・黒井ななこ)に転校。本名を隠すため名簿を「キョン子」だけにし、教室全体に「私の事を気にしなくなる程度の暗示」をかける(さやか・まどかはレジストできる)。「高卒の資格ぐらい取っておこうと思っただけ」「利害関係のない退魔師なんて関わるだけ不愉快」。治癒呪具を「クラスメイト割で1個100万」(通常最低300万)。「金づるになるかもしれない人間相手には営業スマイルを見せる」。「カネは誰も裏切らないからな」。やる夫が親を詮索すると「私の親なんて、放っておけよ! もう居ねぇよ! あんな馬鹿な奴!」「次に詮索したらコンビとやらも全部解消」と帰る。帰路「本心から心配してくれてる人に怒ってんだよ。そんなんだから今でもずっと一人なんだよ」→「一人なら誰にも期待しないで済む! 失うものも無い!」。伊藤誠と遭遇。**父キョン(呪具師)、母涼宮ハルヒ(呪具師)は5年前に人喰い妖魔の村で死亡、キョン子(当時12歳)が誠に連絡する役だった**。誠の演技を「くっさい演技」「私の両親を殺したのだって、お前だろ?」と看破。攻撃用呪具は2枚しか持っておらず(防御・回復が主力商品)「よゆー」と嘘をつく。出典:026 #714-848
  - **第27話(正体判明)**:回想:葬儀の参列者は「呪具師だけでB級妖魔に立ち向かった馬鹿」「助けに行かなくて良かった」と言う退魔師ばかりで、棺は空。**生まれつき人の感情を読む特技**(「なんとなく良い人間、嫌な奴は分かった」、嘘を「嘘……ではない」と判定できる)があり、参列者の本心が全部聞こえた。「なら退魔師ってなんなんだよ!」「人間の死に貴賎なんか無いだろ!」。新城に「お父さん達を生き返らせることは出来ないんですか!?」→断られ、「結局お前だって自分達に利する事しか考えてない」「もう誰かに裏切られるのはたくさんだ! 私は一人で生きていく! 私が家族を生き返らせる!」。12歳で父に並ぶ呪具師(新城)。現在:「まさか私が誠の言葉に同意する日が来ようとはな」。誠の目的を聞いて「分かっただけでも、ちょっとスッキリした」。「十二天将なんて1000年以上前に解散した」と明かした上で、**アーカード(十二天将の一人)を召喚**して阿修羅を一撃で殺させる。「アーカードを見せていいのは、必ず殺す人間か、本当に信頼する相棒だけ」「キョンは最期、彼を呼ばなかったんじゃない。呼べなかったんだ」(主をキョン子に変えていた)。「私はもう誰も信じない。誰にも期待しない。特に退魔師はダメだ。大ッ嫌いだ」と言いつつ、やる夫には「最後に一回だけ期待してみようかと思ってな」とアーカードを見せた。式の維持で「死にそう」。やる夫を治療し、**本名『―――』を明かす**「誰にも言うなよ! 今はお前以外、誰も知らないんだからな!」。それでも「相棒とか気持ち悪い奴じゃない、ただの協力関係」。アーカードの「子作りしろ」に「お前がどうしてもと言うなら何でも……せめてお前の部屋で」と満更でもない。出典:027 #863-889, #897, #941, #966-979, #988-989, 新スレ #4-49
  - **第28話**:やる夫に呪符作りを教えて家を爆破(「私、人に呪符の作り方を教える才能ないわ」)。内心:「私がやる夫と初めて会った時から、ずっとやる夫を監視してる奴が居る」「たぶん誠を殺したのもソイツ」「護衛っぽい監視の仕方」。誠の死体から情報が抜かれないよう「遠距離から呪毒で脳と魂を汚染しておいた」。自宅は安アパート一部屋、呪具製作の道具で「おっさんの部屋」状態。やる夫に「別に私の家で生活してもいいぞ」「寝る所も私と一緒だけど」。**願望機**(死者蘇生用、5年間製作、何億円もつぎ込んだ)を「想像通りだよ」と説明。つかさ「お金大好きだったのってこのため?」→「自分でも分かんないよ。お金は普通に大好きだし」。やる夫が触れた直後、**両親キョンとハルヒが復活**して呆然。読者「こんなんされたらもうキョン子嫁に行くしかない」。出典:028 #138-178
  - **番外編おまけ「キョン子の野望」**:万札の執念だけを剥がす錬金術を試み赤字。「後日、遥かに便利な『全自動エネルギー製造機やる夫』が手に入り凍結」。出典:番外 #309-319
  - **第29話**:やる夫・やらない夫・つかさと4人でD級妖魔を討伐する日常。近くに討伐対象が2体いるから同時に倒そうと提案(全員から「馬鹿」)。「なんと今日だけで3000万円! 私が山ほど使った呪具も、全部やる夫製で無料! こんな利益初めて!」「この近くにもう一人、討伐対象のD級妖魔がいるんだけど……今から皆で行かないか?」「次は1体で2000万円だぞ!?」。「ふふ、でも楽しいな」。読者「キョン子・・・魔性の女!」。出典:029 #421-436
  - **第31話**:ネウロ戦に参加(母ハルヒの「弁償しなさいよ!」に「私の母親は金の亡者か……?」→やる夫「お前が言うのかお」)。**第21話にやる夫へ売った認識呪具に「発信機的な効果」を仕込んでいた**と白状(「座敷童子は居場所の情報だけでも高い値が付く。だから売りたいなぁっと思ってさ」「私は情報を売ってない! つかさを売ってないぞ!?」)。それによりつかさが岩手県遠野に居ると判明。作者「情報売りたかったとか言われれば絶対疑う。金好きキョン子ならなお疑う」。出典:031 #603, #639-645
  - **第32話**:潜入班に同行「私はつかさ、あ、いや座敷童子の捕まってる場所が分かる」。地下でやる夫を先に行かせ「ここは私が抑える」「私は一人の方が戦いやすい」「見ろよ! この呪符の枚数! 全部金で買おうと思うと数億円は下らないぞ?」「戦闘もする呪具師を舐めるなよ?」。出典:032 #749, #760, #812-820
  - **第35話(ネウロ撃破、瀕死)**:中位妖魔3体(天狗・河童・狐火。鎧で妖力を隠していたが種族を見抜く)を五行の特攻呪符で撃破し、天狗には即席で対天狗特攻呪具を作成(「呪具師の強み、その1」)。「中位妖魔を3体同時撃破! 普通なら5000万円ぐらい」。ネウロに「今、お前自分の事を一般人といったか?」と現れられ、アーカードを召喚。ネウロ専用に再調整した呪具で「防御では10倍有利、相生で数倍、相剋で更に数倍」(ネウロ「合計の優位性は100倍位」)を組むが回復に追いつかない。アーカードの「逃げるか? 私の城ならば安全は保障できる」に「私は自分の事しか考えない奴が大ッ嫌いなんだ」「裏切られるくらいなら私が先に裏切る。見捨てられるくらいなら一人で生きていく。そうやって生きてきた。でも、やる夫達には私も期待してしまった。あいつ等は他の退魔師とは違う」「志々雄と戦った時なんて私は2回も逃げたのに、そんなクズをあいつ等は大事な仲間と思ってくれている。そんなの初めてで、嬉しくて」「私はやる夫に背中を任されたんだ。ネウロはここで殺す! 私の命を賭けてでも確実に!」。**自分の心臓を魂ごと呪符に封じた最高威力の火属性呪符**(心臓=火)で「かすり傷」を与え、呪毒でネウロの魔力全体を汚染し300万全てを殺した。魂の心臓部分が欠け「死ぬのはイヤだ……怖いよ」「すまん。泣き言だった。私が決めたことだ。後悔は無い」。最期の命令「やる夫を手伝ってやってくれないか? あいつ、臆病なくせに勇敢で、クズな癖に仲間想いだからさ」「私の代わりに、お前があいつを守ってやってくれないか?」。アーカード「キサマ最後まで結局、命令では無いではないか。だが良かろう」。ねこまたに魂を修復されて生還(「なんか怖いなこの妖魔」)。読者「キョン子こんなに強かったのか」「死ぬのかと思ったが生き残ったか」。出典:035 #324-580
  - **最終話**:生還後、アーカードとネウロの二人を式神として従える(「一度死に掛けて、人間の枠組みからまた少しズレたみたいだ。だいぶ力が増えた。キッツイのは変わらないけどな」)。ネウロに「マスター」と呼ばれ「寒気がする」。シックス戦後「酷いリンチを見た。アイツ一人にA級妖魔何体がかりだ?」「相手能力のタネが分からなきゃ、勝てなかった」「カリチュマ一味とやる夫が組んだら無敵じゃね?」。「やる夫を日本の御旗にする気か?」「私はアイツの協力者だからな。出来る限りの事をやっていく」「アイツの隣に立つならもっと、もっと力が要る」→**「安部清明、十二天将。そいつ等の力を借りたい」**(アーカード「1000年越しの清明再誕か? 私は協力しよう」)。朱雀『ハオ』(輪入道)、六合『アルカ・ゾルディック』(竜宮童子)の情報を得る。やる夫に呪具を無償で作っている。出典:040 #575-578, #643-644, #689-696, #659
  - **番外2(042-044)**:ハワイ旅行に同行(ピトーと組んでビーチバレー)。「ライセンス上、あいつ等(やる夫・やらない夫)はDのまま」「先週の昇級試験で、ふっつーのC級監査官にボロ負け」(042 #851)。アーカード「キサマ、安部清明の再誕を目論でいるんだろう?」「力を誇示するのだキョン子! 名を売れ! 頂に立て(十二天将の側から来てもらえ)」(#880-881)。一般人にも認識される呪符を作れる(#919)。スカウター測定約200万(043 #6)。読心は「今考えている事」しか読めない(042 #939)。ピトーは遠野決戦時からキョン子の秘密(開眼者・安部清明)を知っていた「無駄に広めたりはしない」(#954-956)。おまけ「キョン子の野望2」:土産のペストマスクをハルヒが装着。清明の記録(考案した術式、日記、十二天将)を読み直す(044 #230-233)。
  - **番外5(047)**:「D級でも死を覚悟する必要がある存在、それが妖魔だ」「C級ってのはな、下から4番目じゃないぞ? 上から3番目だ」「Cよりも上には、人外の直轄部隊と地区長しかいない。普通の退魔師にとっては、実質、C級が目指す最終地点」(#586-587)。五行の防御呪符を大量提供する案(却下 #642-653)。金塊を見て「これから私と結婚しないか!?」(#607)。「呪術も魔術も、武術すらも、ルーツをたどれば大本はお前と同じ開眼者が生み出した代物だ。もし全てを十全に使いこなせる奴が居れば、お前レベルで強いのは当然」(#689)。
  - **第2部(048-051)**:「いよいよ新城も本気でやる夫を引っ張り出しに来たって訳だ」「むしろ遅すぎたくらい」「開眼者を野放しには出来ない。手元に置くか、飼い殺しにするか。それが無理なら自分達の上に立ってもらう」「お前は将来、日本の裏のトップに立つ可能性が高い」(048 #801-805)。ずっと安部清明の記録を読んでいる(#812-814)。第3話でやる夫から「今すぐ会いたくなった」と電話され赤面→用件(呪具)を言われず切られる(050 #89-97)。パリストン「『キョン子』さんとの面白い対談を私がセッティング致しましょう」(051 #281)=ハオ(十二天将)と引き合わせる計画。
