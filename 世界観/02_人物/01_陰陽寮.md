# 人物:陰陽寮

陰陽頭・補佐・地区長(首脳部)、各地区長の部下、2ch町を管轄する職員。アカギ配下の式神・天使もここに置く(第14話時点で「アカギの陣営」として整理していたもの)。

## 首脳部(陰陽頭・補佐・地区長)

- **麻呂**(陰陽頭)
  - **第37話・最終話**:本部に保護された座敷童子たちに「麻呂の部屋がこんな座敷童子の美少女で埋め尽くされるとは! まさに天国!」「麻呂は一般人と美少女の味方でおじゃる!」。C.C.に「ピザ追加で持って来い。礼にお前を椅子にしてやろう」と言われ「ハイ! 持ってきますうぅ!」。最終話で「組織および関連する一連の事件の完全収束を宣言」「最大の功労者は新城。さすがは『皇国の守護者』」、新城に引責辞任を「損を押し付けて悪いな」。志々雄「陰陽寮のトップが、お前みたいな愉快な奴とは思わなかった。『陰陽助』はクソの塊だったが」。出典:037 #875-881 / 040 #680-686
  - **第2部(048-049)**:パリストンの選挙上申を「よい。新城が決めたことじゃ。信賞必罰は当然。むしろ、その程度のことしか出来ぬ麻呂が本来はおかしい」と退ける(048 #835)。政治的駆け引きは「全て竜崎に任せる」。「入即出やる夫か……本当に開眼者なのかのぉ?」(#845)。公家との茶会(陰陽寮への支援を引き出す仕事)を「汚いおっさん共と密室で茶を飲む」「zip探しの時間が減る」と嫌がる(#847-850)。政府は陰陽頭の挿げ替え(役人の出向)を狙ったが座は死守(#831)。就任式では「C級退魔師」として来賓紹介(049 #908)。やる夫に「見れば見るほど凡庸よ」「挨拶は最悪」と言ってから「なーんてな!」(#954-956)。隠蔽呪符を外したやる夫の圧力に「麻呂には開眼者かどうかは見分けはつかん! しかし圧力が莫大に増えた!」(#963)。
  - **第2部第25話(072 #837-858)・本部襲撃**:名は**一条公麿**、官位は三位中納言(妖魔「一条公麿三位中納言……ッ!」)。「……騒がしい。何事か」。竜崎の「これは僕たち、死にますね」に「ほほほ、そうかそうか。つまり麻呂は、これで終わりか……思えば、つまらぬ人生であった」。回想:50年前、由緒ある公家に生まれ「『お家のために。日本のために』そこに自分の意思はなく、ただ決まりきったレールを歩む人生」。「麻呂は陰陽頭として情熱が無ければ、能力もない。ただ周りが求めるがままに、お飾りで腰かけていただけの地位」「重大な仕事は、有能な補佐に全て投げた。麻呂はネットの世界で遊び惚け、甘美な画像に溺れる毎日」「それでも情報は入ってくる。醜悪な妖魔の世界を嫌でも見てしまう」「最期ぐらい、誰かに押し付けられた、陰陽頭ではなく……1人の退魔師として。幼い頃、自分が思い描いていた正義の味方として、貴様らを滅してみせよう」「推して参る!」。生死は未出(→99)。
  - **第2部第32〜34話(079 #380-441 / 080 / 081)・生存とハッタリ**:「蹴鞠だけが、公家の必修科目だと思うなよ!」「京八流奥義……!八艘跳び!」で残像と同時斬撃を見せるが「幻の剣を見た。……麻呂が奥義を使えるはず無かろう。ばーか、ばーか」(傷一つ付けられず)→「ひえっ!コイツ等早い!」「竜崎ぃいいい!!もう時間稼ぎ限界!助けて―!」「麻呂の超絶技巧と最強の剣術、高い結界呪具でなんとか、時間を稼いでおるが」「この麻呂をして、1体も殺せんぞ!?」「腐れアカギィイイイ!早く来いぃいい!」。アカギ到着に「麻呂の寝所を襲った天誅じゃ!……行け!アカギ!」。地下牢の食蜂が本物と分かり「カカカカ!偽情報をつかまされたな!パリストン!」。第33話、パリストンに「『何もしていない』!?貴様ッ!!よくもそんな、いけしゃあしゃあと虚言を抜かせるものじゃな!!」「ただの権力争いなら、こちらも強硬手段はとらぬ。しかし貴様はやりすぎた!限度を知らぬにもほどがある!!」、ハオの証言を受け「文句なしの外患罪じゃ。その死を持って、贖いとなせ」「最期の言葉はあるか?」。内心、愛染を「パリストンほど無遠慮ではないし、こちらの味方でもある。しかし決して完全な味方とは言えない。後でチクチクと麻呂を責め立てるつもりだろうが……パリストンよりは遥かにマシだ。許すべきだな」。第34話「あんのパリストンめぇ……最後に嫌らしい置き土産を残していきおって」「まさか開眼者を野に埋もれさせておく訳にもいかないじゃろう!?」「ようやくパリストンを排し、陰陽寮が正常に戻ったんじゃ!開眼者を公表する手はずも整う!麻呂たちで守れる!……すべて、奴が地区長の役職に居ればな!」「なんでやる夫なんかが開眼者なんじゃ!アイツは一体、何の開眼者なんじゃぁあああ!?」「もっと働け!クソニートぉおおお!!」。
  - 第15話:掲示板では「うるせえ麻呂」「あんなんでも日本の退魔師会のトップ、綺麗に飾ってある」と扱われ、本人は毎日ネット工作をしても効果がなく悩む。竜崎「居ても居なくても一緒」
  - 陰陽寮の頂点。平安時代から続く名家出身の退魔師。「〜でおじゃる」「だまりゃ!」。調停者として多数決には加わらない。殺人事件は警察の領分という方針。雑誌『陰陽寮のひと時』を出す。出典:010 #1332-1390

- **竜崎**(陰陽寮補佐)
  - **第25話(24時の密談)**:新城と裏切り者の捜査を共同で進めている。東北の大発生を「想定範囲」「基本はあなた(新城)の策」「このまま継続」と、住民の犠牲を織り込んで敵を釣る方針。新城を「9のために1を切り捨てるのが得意」と評す。候補:シックス「真っ白。彼ほど日本の為に働いている地区長は居ない。在位200年」、藍染「不正だらけ。賄賂、脅迫、策謀。実力は地区長最下位。野心が溢れ出ている。アカギが失脚すれば自分の息が掛かった人材を推薦できる」、博麗・才人&ルイズは「問題ない」。「民間退魔師がいくらか殺されただけなら、まだ良い。問題は人類を裏切っている可能性」。アカギの監視カメラ映像は「偽者です」と即断、「目的を教えて貰えれば協力できる。無理なら利用するだけ」。「私達はアナタ方の目論見どおり動いていますよ。対して、アナタはどう動きますか?」。出典:025 #678-701
  - **第29話**:新城に「つかさの情報、売らないのか……」と驚き「炊き付けたのか」と見抜く。「なら、アカギはどう誘導する? 来るか?」。出典:029 #360-366
  - **第32話**:前線基地で作戦説明「ここまでは全て予定調和。ここからが騙し合いの始まり」「敵が求めているのは陰陽寮との決戦ではなく、戦闘行為そのもの、その余波で生じる大量のエネルギー」「一つ情報筋もあるが信用しすぎないほうが良い」。「私ならば遠野は囮にする」。座敷童子は「非常に高度な隠蔽術」で捜索できず「戦争開始は先延ばし」「最悪、一時的な撤退もありえる」→キョン子の発信機で遠野と判明し救出部隊を編成。出典:032 #732-742
  - **第39〜40話**:「まずいな。シックスが強すぎる。勝ち筋が無い」(アカギ「それをどうにかすんのがお前の仕事だろ!?」)。最終話「さすがに自衛隊を全力で動かすほどの事態でしたからね。政府の方が黙ってません。なんとか新城さんのクビ一つで話を付けましたが……政府には無能しか居ないんですかね?」。麻呂「竜崎の奴、流石でおじゃるな! 敵から離反者(ゼロ)を出すとは!」=ゼロの離反は竜崎の工作(◎)。出典:037 #875 / 039 #438 / 040 #683
  - **番外4(046)**:新城の送別会に出席。「下戸の飲兵衛(霊夢)は放っておくとして」(#450)。「酒呑童子を式神に? 馬鹿かね君は」(#451)。「まさか能力が危険という理由だけで(殺さない)」(#476)。妖魔との「融和方針」の立案者(ルイズ「麻呂ではなく竜崎」#477)。シックス消滅の真実を知る二人のうちの一人(#447)。
  - **第2部(048-051)**:パリストンに「これは既に決定事項です」「私は新城さんが辞任すること自体、反対なんです」(048 #827)。パリストン評「シックスが片付いたと思ったら次はパリストン」「嘘と真実が入り混じってそう。シックスの作った土台を彼が利用した」「何が目的なんだか。解雇したいところ」(#839-840)。「東北地区長の選出を選挙にしなくて良かった。そんな事をすればパリストンの思う壺。東北が彼の勢力下になる所でした」(#842)。「開眼者って、どんな力を持つ人物なんでしょうね? さっぱり分からない」(#846)。やる夫の隠蔽解除に「見ただけで分かる。貴方は異常だ。新城さんの話に信憑性が増しました」(049 #963)、「先ほどの演説、アレはアレで良かったかもしれません」(#964)。第4話:「やる夫さんが就任挨拶に失敗してくれたおかげで、パリストンの狙い所が分かり易くなって良かった」「不信任案決議から再選挙」「数か月の猶予で確実な味方を準備し、選挙で正面から迎え撃つ」→「パリストンの動きが予想よりも早すぎる」(051 #228-231)。「本人からやる気が感じられない。それが一番致命的」(#235)。「パリストンは基本的に私とは正反対の方針。彼がトップに立ったら日本は徹底した妖魔排斥主義国家になります。ヨーロッパの仲間入り」「つかささんや、かがみさんも無条件で退魔の対象」(#255-257)。「脅しってあんまり好きじゃないんですよ、私」(#258)。「(なんて操りやすい人だぁ)」(#253)。
  - **第2部第5話(052 #373-409)・直轄部隊対策の設計者**:やる夫に「最初は高圧的に。間違ってもへりくだってはいけません」。「彼らは全員、超一流の退魔師。プライドも相応に高い」「普通でもダメ。パリストンに直轄部隊を持っていかれる」「『新選組』なんか引き抜かれたら最悪」「『うちは』と『三千院』は抜けるでしょう」。「今日、ほんの僅かな顔通しだけで絶対の信頼を勝ち取る必要がある」→「いいえ不可能です」。開眼者を明かす利害(「生きた偉人の再来」vs 中国のトップ・世界各国のすり寄り・パリストンとの結託・人質・洗脳・研究対象化、「『世界』対『日本の一部』」)を整理し、「実力を見せていいのは精々、直轄部隊ぐらい」。「うちはイタチと三千院家執事達、あの3人はもう無理ですね。各家から不信を買ってますので恐らく一度脱退します」。「せめて直轄部隊の全員を相手に勝つ! なんてパフォーマンスができれば最高」→やる夫「別にいいお」に「自分が何を言っているか分かっているんですか?」。土方を「さくら」として仕込み、報酬を「自然な形で新選組に渡す」(#520-527)。模擬戦を見て「(やはり、今までの凡愚は演出か? 土方の本気の威圧に一歩も引いていない。面白いな)」(#356)。第8話:転移陣の予算を優先的に東北へ回している(055 #931)。
  - **第2部第20〜23話(067-070)**:さとりに帰還命令(067 #983)。電子精霊を東北に貸し出したことがパリストンの攻撃材料に(#892, #953)。同時多発襲撃の報告に「東北支部、北海道、宮城支部、新城家、果てには恐山にまで同時攻撃!?」「合計で中位妖魔300体、B級15体、A級1体!?あり得ないッ!!」「A級は少ないけど、それ以外の数は、かつての組織の全力に匹敵する」「パリストン?あり得ない。彼がそんな戦力を持っているはずがない。好戦的な妖魔が人間に従うはずがない」(070 #450-455)。
  - **第2部第25話(072 #841-843)**:本部襲撃時、麻呂の傍らで「通信が妨害されました。外部との連絡一切不能。いま応援が来る可能性は、非常に低い」「……陰陽頭。これは僕たち、死にますね。最悪」。麻呂が「重大な仕事は、有能な補佐に全て投げた」と言う補佐=竜崎。
  - **第2部第32〜34話**:「麻呂ぉおおお!もうちょっと、頑張れ!10分ぐらい粘れぇええ!!防御用の呪具だって有限なんですよー!?!」(079 #407-415)。地下牢で「食蜂さんは歴とした人間だ!それを、愛染さんもアカギさんも確認した!これで満足ですか!?パリストン!」(#464)。第33話、パリストン追及の主導「では、言い訳をどうぞ。好きなだけ屁理屈を並べ立ててください。自己保身をどうぞ」、テープレコーダーを提示「どこからどう聞いてもパリストンさんですね。おおっと名前まで出た!」「さすがに真相究明なく推測だけで排除はしません。ですが、情報提供者がいらっしゃったもので……(ハオ)」。処刑後「できれば、法に則って捕まえたかった。だけど申し訳ありません、パリストンさん。貴方は厄介過ぎた。裁判なんかしていては、必ず復活する。だから、こんな勝ち方しかできない。僕を恨んでください。貴方にはその権利がある」(080 #662-664)。→第25話の密談で大発生を「継続」させた判断と同じ流儀(提供者の指摘。危ない手段は昔から)。不信任決議に「そ、それは、なんなんですか!?愛染さん!」。第34話「諦めましょうか。やる夫さん、きっと今頃喜んでるんだろうなぁ……死んでも地区長選なんか出ない気がする」「愛染さんも能力はあるけど野心が強いですからね。いつでも陰陽頭の座を狙ってる。自分から人類や日本の不利益になる事はしないからいいけど」「やる夫さんが開眼者であると公表すれば、愛染さんは納得してすぐに引く。絶対に敵対しない。選挙も余裕の勝利」「ならないぞ!彼はもうパリストンを倒して安心している!断言しよう!もう絶対に働かない!」(081 #806-812)。
  - 第20話:第2章の事件を「私の落ち度」「相手を見誤った私の責任」と自ら認め、シックス・藍染に責められるが麻呂が続投を決定(「竜崎に辞められたら本部の頭脳が麻呂になってしまう! 日本が滅ぶ!」)。取り調べで御宅が捨て駒と見抜き、「これは組織の……延いては夜神月の作戦じゃない」と判定(被害者が重犯罪者に限られ、一般人の被害が少なく、陰陽寮の準備を待つような時間差があった)。**組織の目的は人類攻撃ではなくエネルギー集めだったと初めて推測**。内心:「殺傷事件は僕が『この場』で告発した途端に全て止まった。アカギが主犯ならそんなあからさまな事をするものか。彼以外にナニカ潜んでいる」「アカギの思惑、組織の動向、やる夫君たちの今後……僕一人の手には余る。だが他の地区長に知られるのはもっと困る」「新城さんのあの顔、困ってそう」
  - 「今の陰陽寮、実質のトップ」(ルルーシュ)。ランク制度の設計者で「少し有能」(やる夫)。殺傷事件を「大した事件ではありません」「我々は警察じゃない」と言い切る。アカギに「貴方が犯人ですね!?」と迫るが「私もアカギ地区長を信じたい」とも言い、監視案を出す。内心「アカギは嘘を吐いている」「新城も何か隠している」。出典:010 #1347-1385, #1428-1438

- **シックス**(近畿地区長)
