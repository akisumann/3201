この表は**移行作業の設計図**であり、まだ何も移動・削除していない。

判定の意味：

- **一致** … 同名の個人ファイルがある
- **一致(表記差)** … 表記が違うが同一人物とみなせる
- **複数人** … 旧項目が複数人をまとめている。個人ファイルへ分割が必要
- **別人物の可能性** … 「〜の父」「〜たち」など、似た名前だが別の人物・集団。候補は参考
- **要確認** … 自動判定では決められない。一件ずつ中身を見る
- **未対応** … 個人ファイルがない。モブ・集団・一話限りの妖魔個体を多く含む

2. **複数人**：人物ごとに分割して各個人ファイルへ。分割できない共同記述は残す側を決める。
3. **別人物の可能性／要確認**：一件ずつ内容を見て、既存ファイルへの追記か新規作成かを決める。
4. **未対応**：名前付き人物なら個人ファイルを作る。モブ・集団・一話限りの妖魔個体は `02_人物/モブ・集団.md` へまとめる。妖魔の種族・個体として扱うべきものは `01_用語集/03_妖魔.md` 側へ。
5. 各段階のあとで、旧ファイルの全行が移行先のどこかに存在することを行単位で照合する。
6. 照合が済んだ陣営ファイルから索引化する。**照合前に削除しない。**
