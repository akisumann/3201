# 三世右衛門尉村正

> 現収録分001〜137時点の整理。原稿131（第6部第2話）で初登場。

## 要約

- **正体**: やる夫のカードから実体化した**装備可能**な妖魔。キョン子が護衛用カードの中から選んだ。
- **特徴**: 紫がカード妖魔の仕組みを説明した直後に召喚されたため、**カードとしての自我が強く、モデルの性格はかなり弱まっている**。
- **呪い**: 装備者に「**善悪相殺**」（敵を殺した数だけ味方を殺さねばならない）が掛かる。
- **現状**: やる夫が呪いを消した**弱体化版**で装備されている。

## 時系列記録

### 第6部（原稿130〜133）

#### 原稿131・召喚

キョン子が「装備可能」という条件で選んだカード。召喚された本人が違和感を口にする。

- 「というか私を**通常召喚**って、珍しいわね……。」
- 「**御堂**が変な事を聞いてくるんだけど……。」（やる夫を「御堂」と呼ぶ）

紫の分析。

- 「生み出す際の自我や能力は、やる夫の意志一つだからね。**さっき私が伝えた情報が影響したんでしょう。** 恐らく**カードとしての自我が強くなり、モデルの性格はかなり弱まった**わね。」

→ 紫が直前に「カードは付喪神で、平行世界のモデルと融合したもの」と説明したことが、そのまま召喚結果に反映された例。

#### 原稿131・「善悪相殺」の呪い

- 「止めた方がいいわよ？　**私を装備すれば、呪われる。**」
- 「『**善悪相殺**』の呪い。**敵を殺せば、その数だけ味方を殺さなくちゃならない。** 貴方そんな呪い欲しい？」
- キョン子「あのカードテキスト、**そこまで再現するのか？** マジもんの呪いなのか……？」

#### 原稿131・呪いを消すと能力も落ちる

やる夫が呪いだけを消そうとするが両立しない。

- 「確かに呪いは消えたけど、その代わり、**私の能力も性能も格段に落ちたみたい。『磁気操作』まで無くなってる。** 私、ただの雑魚効果モンスターになったわよ？」
- 30回やり直しても両立せず「御堂……**もう諦めたら？　30回はやったわよ？**」
- キョン子「やる夫の奴、たぶん**無意識でゲームバランス考慮してやがるな**……？　**想像力次第で、どうとでもなる筈なのに**……。」
- つかさ「やる夫さん能力を殆ど制御出来て無いんだもん。**あの人も言ってたよ……やる夫さんは力を1%も使えてないって。**」

結局デメリット消しの弱体化版で装備した。合体は激痛を伴う（やる夫「痛ッッェエエエエ！！　なにその合体方法！」）。表示は「**やる夫in劒冑**」。やる夫「どう？　今のやる夫、格好よくない……？」→無視された。


### 第6部（原稿134〜137）

#### 原稿136・やる夫のB級昇格試験での初実戦

「助けてみんなー戦法」で**2番目**に呼ばれ、**劔冑としてやる夫を覆った**。(136 #180-191)

- 「まったくもう！　だから**戦いが始まる前に劔冑を纏っておきなさいっての！**」
- 表示「やる夫in劔冑」→やる夫「はーはっはっは！　**三世村正を装備したやる夫は硬いおー！**」→**直後にアンデルセンの一撃が貫通する。**
- 「**あ、ごめん。無理。貫通した。**」「……え？　**やっぱ私ダメだ。傷の修復はできるけど、別の護衛を呼んだ方がいいかも**、次が来た。」
- 御坂美琴の苦言「**デフェンダーを呼ぶ順番間違ってんじゃないの！？** なんで村正を一番に呼んだわけ？　**今のアイツ、滅茶苦茶弱いんだから、止めなさいって。**」
- アンデルセンの査定「**蜘蛛のような甲冑はD級。**」

→ 131で**呪いを消した弱体化版**として装備されたことが、そのまま実戦での脆さになって表れた。「**傷の修復はできる**」という機能が残っていることも確認された。

## 能力

- **装備可能**（通常召喚も可能だが珍しい、と本人が言う）。
- 本来は「**磁気操作**」を持つ。呪いを消した版では失われている。
- 呪い「**善悪相殺**」＝敵を殺せば、その数だけ味方を殺さなくてはならない。

## 未確定・注意

- **第1部・第3部に登場する「妖刀村正」とは別物として扱う。** 妖刀村正は室町時代に作られた霊刀で、「握った者には歴代所有者の経験と力が授けられるが、代わりに魂まで寄生される」もの（086 #548-557）。こちらは**やる夫のカードから生まれた存在**であり、直接の関係は作中で語られていない。
- 「善悪相殺」と、新城直衛の「相殺」技術（アストレアが「コイツ以外の生物には真似できない」と評したもの）との関係も語られていない。→`../../99_未確定/01_矛盾・要注意.md`
- やる夫を「御堂」と呼ぶ理由は、カードとしての自我が強まった結果とされる。モデルが誰かは明示されていない。
- 弱体化版のまま運用されるのか、後で作り直されるのかは未確定。
