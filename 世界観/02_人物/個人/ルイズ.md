# ルイズ

> 現収録分001〜137時点の整理。詳細な各話ログは旧 `01_陰陽寮.md` と `07_読書スナップショット/` を参照。

## 要約

- **立場**: フランス出身の英雄。平賀才人の妻。日本では九州地区長。
- **能力・役割**: **典型的な後衛魔法使い。一番強いのは虚無の魔法で、詠唱なしで範囲爆殺、詠唱ありきならあらゆる防御を無意味にして超範囲爆殺**（提供者の指摘 ◎）。妖力3億の地区長級(115 #952-957)だが、**近距離に接近されたら置物**(046 #460)。詠唱なしで**最大爆破半径300m・初期型核兵器の数割**、完全詠唱なら**威力数十倍＋防御を無意味にする**が**1時間かかる**(100 #892-902)。**威力を絞れない**ため味方を退避させてからでないと撃てない。
- **人格の核**: 気が強く口も悪いが、英雄扱いを重荷に感じる普通の若い女性でもある。責任感は強い。
- **主な関係**: 才人は夫・相棒。ジャンヌは師。キュルケ・タバサは同門。藍染は来日時の受け入れ側。
- **現在の状況**: 九州地区長として在任。パリストン派の粛清や陰陽寮の定例報告に参加。

## 人物像

ルイズは、フランスでは世界規模の危機を救った英雄だが、本人は「英雄」という肩書きを素直には受け入れていない。

十代後半でベルゼブブ事件を経験し、多数の犠牲者を見たため、「自分が勝ったから英雄」という単純な物語に違和感を抱く。

日本へ移住した後は、本人の意思に反して九州地区長へ推薦され、そのまま当選。国外英雄から日本の地方統括者へ立場が変わっている。

## 時系列記録

### ゼロのルイズ

- 十年前、使い魔召喚で日本人の平賀才人をフランスへ召喚。
- 魔法を使うと何でも爆発してしまうため「ゼロのルイズ」と呼ばれていた。
- ジャンヌに導かれ、仲間と死線を潜り抜ける中で『虚無』の才能を開花。
- 才人とは喧嘩と共闘を重ね、互いを意識する関係になる。

### ベルゼブブ決戦

- フランスを襲ったベルゼブブと戦う。
- 最終局面では味方退避後、才人と二人で敵へ挑む。
- 完全詠唱の【エクスプロージョン】で決着。
- 戦後、フランス大統領ポルナレフからレジオン・ドヌール勲章グランクロワを授与される。
- しかし本人は大量の死者を前に「なんで私が英雄なのよ」と苦悩。
- ジャンヌから「貴女がいなければ欧州が地獄になっていた」と諭される。

### 才人との結婚・来日

- 才人が「この戦いが終わったら結婚する」と決めており、その後日本へ。
- ジャンヌはルイズがフランス政治に利用され続けることを危惧し、移住を後押し。
- 8年前、才人と日本へ来る。
- 藍染が受け入れ役として迎える。

### 新城との模擬戦

- 来日直後、新城直衛と実力確認の模擬戦。
- 詠唱破棄のエクスプロージョンを二度使用するが、新城には通じない。
- 才人ごと撃つ判断もするが、デルフリンガーで吸収する前提の連携。
- 新城から「完全詠唱なら自分は死んでいた」と評価される一方、詠唱破棄の使い方には改善点を指摘される。

### 九州地区長就任

- 本人の予想に反して九州地区長へ推薦される。
- 「誰よ、私を地区長に推薦した馬鹿」と激怒するが、そのまま当選。
- 初日の直轄部隊顔合わせでは、日本の退魔師・妖魔の水準の高さに絶句。
- 新城、豊久、信長らの戦闘常識を見て「日本狂ってる」と愚痴る。

### 遠野決戦

- 才人と共に参戦。
- 【エクスプロージョン】で城の地表部を吹き飛ばし、多数の妖魔を巻き込む。
- 一方通行とも交戦。
- 才人のデルフリンガーと組むことで、能力無効化と大火力を両立。

### 第3部

- パリストン派の粛清を九州で進めるが、他地区より出遅れ気味。
- 定例報告会では進捗25%程度と報告。
- パリストンの怨霊化を「人間の枠組みを踏み外した」と分析。
- 国家予算級の被害額に素直に驚く。

### 第4部第12話

- 才人の卒業試験を九州側の仲間と見守る。
- 日本の退魔師層の厚さに改めて驚き、世界征服すら可能ではないかと口にする。
- キリスト教側にA級相当の大司教が数十人いるという説明を知らず、ベルゼブブ戦でもっと戦力を集中できなかったのか疑問を示す。
- 電話で、全キリスト教会への立ち入り調査と、東北でイスカリオテが戦闘中との連絡を受ける。

### 第6部（原稿130〜133）

#### 原稿132・定例報告会

- 開眼者の公表に素直に驚く。「なんでみんな、そんな冷静なの？　開眼者よ？　**しかも聞けば、シックスを倒したのも実はやる夫！？**」
- 開眼方法に「10年間、1つの事だけをし続けたの？　他の事はしないで？」「**ありえないでしょぉおおー！？** それでどうやって生きて来たのよ！？」
- 教義改竄の共有では「**なんでアンタがそんな事を知ってるの！！？**」と竜崎に問う。
- 日仏関係の説明を受けて「キリスト教が落ち着いて、日本と敵対することが無くなったら**私の意志と、両国政府の協議で私と才人がフランスに戻る可能性も0じゃない。**」と述べる。

また、麻呂の説明で**ルイズと才人が「臨時」地区長なのは二人一組のため**であることが明かされた（実力は「まあまあ十分。殲滅戦なら申し分なし」）。


### 第6部（原稿134〜137）

#### 原稿134・『始まりの開眼者』の写本を持ち出す

九州支部の禁書庫で、**フランスから持って来た魔導書**を探し出す。(134 #801-805)

- 「私が母国から持って来た魔導書のどこかに、**開眼者に関する記述**があった気がしてね……。**フランス国宝の写本**だから、信憑性は有ると思うんだけど……。」
- 信長が勝手に読み出すと「ちょ、ちょっとーー！！　**勝手に読むな！！　それ門外不出の国家機密よ！！？** なにフランスの国宝にイチャモンつけてんのよ！！」「**消せ！　消すのよ！！　今すぐ記憶を消しなさい！　これは地区長命令なんだからねー！！**」

記述が途中で切れていることについて。

- 「……**これは写本よ。原本にもそこは載って無いんじゃない？** なにせ数千年前から受け継がれてきた、書物。**経年劣化で失われたか……あるいは、開眼者がそれは残させなかったか……。はたまた……残せなかったのか。**」
- やる夫について「ま、なんにしろ……やる夫はその開眼者だからね。**こりゃ本気を出したら世界征服できるんじゃない？　ホンモノの神にも勝てる力が有るなら、よゆーでしょ。**」
- 「**この歴史書にある開眼者の記述を読む限り、力はそれに匹敵するはず。一体ニートがどんなぶっ壊れになってるかしら……。あーこわ。**」

→ **「開眼者は神に勝てる」**という評価が、伝承に基づいて出た。信長には「**チンマイ**」と呼ばれて揉めている。

## 能力・戦闘特性

**★ 典型的な後衛魔法使い。いくらかの魔法は保有しているが、一番強いのは虚無の魔法。詠唱なしで範囲爆殺、詠唱ありきならあらゆる防御を無意味にして超範囲爆殺。**（提供者の指摘 ◎）

| | |
|---|---|
| 保有力量 | **妖力3億**（できる夫の挙げる日本の保有力量。新城1億8000万／アカギ2億／藍染1億3000万／博麗7億と並ぶ、115 #952-957） |
| 型 | **完全な後衛。** 「**私は近距離に接近されたら、もう置物なの！**」(046 #460) |
| **詠唱なし** | 『エクスプロージョン』**最大爆破半径300m／初期型核兵器の数割**(100 #892)。ただし**戦闘慣れした者には防がれる** |
| **完全詠唱** | **威力数十倍**、そのうえ**あらゆる防御が無意味になる**(100 #901)。ただし**1時間かかる**(100 #902) |
| 制御 | **できない。** 「**超広域爆破か、超々広域爆破しかできないの！**」(046 #460) |
| 相棒 | **平賀才人**。封魔の剣は「**ルイズ君と一緒に戦っている時しか能力を使えない**」(046 #461)＝**相互依存** |

### ★ 典型的な後衛 ― 近づかれたら置物

**本人が言い切っている。** 一方通行を取り逃がして藍染と竜崎に責められた場面。

> ルイズ「それに**私は接近戦はできないの！　敵と一緒に自爆しろって言うの！？**」(046 #459)
> ルイズ「**私は近距離に接近されたら、もう置物なの！　爆破魔術の威力制御は大の苦手なの！　超広域爆破か、超々広域爆破しかできないの！　それぐらい知ってるでしょ！**」(046 #460)

**→ 威力を絞れないことが、そのまま近接不可の理由になっている。** 小さく撃てないので、敵が近ければ自分も巻き込む。**地区長級の妖力3億を持ちながら、間合いを詰められた時点で戦力がゼロになる。**

**才人との相互依存。** 才人の封魔の剣も「**ルイズ君と一緒に戦っている時しか能力を使えない**」(046 #461)。**二人でようやく一組**で、片方だけでは成立しない。

### ★ 詠唱なし ― 半径300m、初期型核兵器の数割

**通常運用がこれ。** 新城が模擬戦の検討会で数値を出している。

> 新城「まずは初手のルイズ君の爆発魔法。**あれは頂けないな。**」
> 新城「**最大爆破半径300mくらいか？　初期型核兵器の数割程度の威力は有るが……それだけだ。**」(100 #892)
> 新城「**そんなもの、戦闘慣れしている者ならば簡単に防げる。煙幕にもなる。一手二手無駄にするようなものだ。**」(100 #894)

**→ 一般的な基準では規格外だが、地区長級には通らない。** 才人も「**開幕ルイズの爆殺戦法なら**」と当てにしていたが、新城は爆発を突破して才人の脇を抜け、ルイズへ迫っている(100 #816, #865)。

### ★★ 完全詠唱 ― あらゆる防御を無意味にする

**これが「虚無」の真価。** 新城の評が、一文の内容をそのまま言っている。

> 新城「君の魔法はあんなものじゃないだろう？　**なぜ詠唱破棄した？　完全詠唱ならば僕はここに居ない。何も出来ず、死んでいた。**」(100 #899)
> 新城「**詠唱さえすれば、魔法の威力は数十倍に膨れ上がり、『虚無』の真価も発揮されると聞いた。こざかしい細工は、何の意味もなさず全てを無に帰す。素晴らしい魔法だ。**」(100 #901)

**「こざかしい細工は、何の意味もなさず全てを無に帰す」＝防御・小細工が効かない。** 詠唱なしの爆発は「戦闘慣れしている者ならば簡単に防げる」と切り捨てた同じ相手が、**完全詠唱なら自分が死んでいたと認めている。**

**★ ただし1時間かかる。**

> 新城「つまり、君たちが勝つなら**ルイズ君が真っ先に詠唱を始めて、終わるまで才人君が僕の攻撃から守り抜く。** それが良かった。」
> ルイズ「サイトはアンタに一瞬で沈められたけど……？　**私の完全詠唱は、1時間くらい掛かるけど？**」(100 #902)

**→ 正解の戦い方は作中で示されている。「才人が1時間守り切る」。** そして**それが現実的でないことも同時に示されている**（才人は新城に一瞬で沈められた）。**この一組の課題がそのまま能力の形になっている。**

### 完全詠唱の唯一の実戦 ― ベルゼブブ撃破

**現収録分で完全詠唱が通ったのは、番外7（099）の一度だけ。** 相手は聖書の悪魔ベルゼブブ。子蝿一匹でもE級妖魔級で、宿主へ卵を植え付け**30分で羽化・破裂させて数千匹へ増殖**する。増殖速度が人類側の駆除速度を上回り、**フランス発の「黒き死の病」が欧州全土へ広がりかねない危機**だった(099 #757)。

**勝ち筋は、範囲の大きさを前提に組まれている。**

1. **キリスト教側が信徒の祈りを利用して、フランス全土の子蝿を戦場へ集約した**(099 #757)。
2. **味方を全員退避させる。** 「祈りによって味方側の人間たちが戦場から退避」(099 #716)、残ったのは「**私と才人！　そして、お前しかいない！！**」(099 #717)
3. **完全詠唱を撃つ。** 「**完全詠唱の私の一撃よ！　ここら一帯！　みんなもろ共巻き込んでッッ　吹き飛びなさい！！**」「**エクスプロージョン！！**」(099 #718-719)
4. **才人がデルフリンガーでルイズ本人を爆風から庇う**(099 #721-723)。ルイズ自身が「**ここまで爆風が来るッ！**」と言っており、**術者も爆心圏内にいる。**

**ベルゼブブと子蝿をまとめて消し飛ばした。** 戦後、フランス大統領ポルナレフから**レジオン・ドヌール勲章『グランクロワ』**を授与され、「世界を救った英雄」とされている(099 #757)。

**→ 制御できないことを、戦術で強みに変えた唯一の例。** 敵を一箇所へ集め、味方を退かせ、撃つ。**超々広域しか撃てないという欠点が、そのまま解になっている。**

### 弱点

1. **近づかれたら終わり。** 「近距離に接近されたら、もう置物」(046 #460)。実際、模擬戦で新城は爆発を突破して才人の脇を抜け、ルイズへ到達している(100 #865)。
2. **完全詠唱に1時間。** 守り切れる前衛が必要で、才人は新城に一瞬で沈められた(100 #902)。
3. **威力を絞れない。** 味方が戦場に残っていると撃てない。ベルゼブブ戦は**全員退避させてから**撃っている。
4. **詠唱なしでは地区長級に通らない。** 新城「戦闘慣れしている者ならば簡単に防げる」(100 #894)。
5. **一方通行を取り逃がしている**(046 #458-460)。藍染「……なにをやっている？」、竜崎「**地区長があんな雑魚に後れを取るなど……あってはならない失態だぞ**」。

## 未確定・注意

- 現在年齢は明言されていないが、8年前に「まだ20にも満たない」とされているため、現時点では20代半ば〜後半程度と推定される。
