# 諸葛孔明

> 現収録分001〜133時点の整理。2026-09-19に新規作成。**話者ラベルの走査で、個人ファイルが無いまま複数話に登場していたことが判明したもの。**

## 要約

- **立場**: 中国。国家主席**曹操（華琳）**の**護衛**にして**策士**。表示は「策士　孔明」。
- **役割**: 盟約会合で中国側の実務提案を担い、曹操の判断材料を即答で出す。
- **人物像**: 礼を尽くした言い回しをするが、内容は容赦がない。可能・不可能の線引きを曲げない。

## 時系列記録

### 番外10（原稿102）・第71回盟約会合

- 自己紹介「**曹操様の護衛は　私、諸葛孔明と**」→ 呂布が「恋が、きた……。」と続ける（102 #80）。表示は「**策士　孔明**」。
- 日本の人材について切り込む。「では、日本ついでに　**私から提案を一つ。**」「先日、**入即出やる夫が地区長選挙に出馬表明**なされましたな」「対抗馬は、かの三千院家とか。」「いやはや、**日本は人材豊富で羨ましい！　ぜひその知識、技術を少しは**――」（102 #535-551）
- 藍染の共同勉強会案の参加資格については、プッチの「特A級妖魔を自国だけで退魔できること」に対して緩和案を出しかけ、自分で撤回する。「『**A級妖魔**』でもよろしいのでは？」「おっと、それでは列強以外が、参加できないな。」「**国防の要を遊ばせる訳にはいかんだろう**」→「はっはっは！　**藍染殿の案で行きましょう。**」（102 #168-169）

→ **提案を出して自分で潰し、最後は相手の案に乗る**という進め方をしている。

### 第5部第2話（原稿126）・やる夫の「悪夢」への判定

やる夫が世界中の超常を知る全存在へ同じ夢を見せたことについて、曹操が孔明へ確認する。

- 曹操「……孔明。**そんな事は、可能かしら？**」（126 #325）
- 諸葛孔明「**個人の力でそれを為すことが、本当に可能であると思っているならば　今すぐ辞表を提出致しましょう。**」「**私はそんな愚者の下では働けない**……。」

→ 中国の策士が「**個人にできるはずがない**」と断言した直後に、実際それをやる夫がやってのけている。**開眼者の異常さを外部の専門家の口で測る**役になっている。
