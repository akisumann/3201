# 人物ノート案内

人物情報は長年の追記で、陣営・立場ごとの巨大ファイルへ集積しています。現収録分001〜119を一通り確認し、読書スナップショットも作成済みとなったため、2026-09-17から主要人物の**1人1ファイル化**を進めています。

旧巨大ファイルは証拠・詳細ログとして残し、新個人ファイルとの照合が終わるまで削除しません。

## 現在の構造

### `個人/`

1人1ファイルの整理版です。

人物数が90人を超え、手書きの全件一覧は更新のたびに陳腐化するため、**作成済み人物の正本は `個人/` ディレクトリそのもの**とします。このREADMEでは人数や全ファイル名を固定列挙しません。

各個人ファイルは、主に以下を短時間で掴むためのものです。

- 現収録時点での立場
- 初期から現在までの変化
- 能力・技術
- 主な人間関係
- 後から判明した真相と、当時の見え方の違い
- 未確定事項・誤認しやすい点

## 個人ファイルの作成状況

旧・陣営別ファイルの項目のうち、名前を持つ主要人物はおおむね個人ファイル化済み。未作成のまま残っているのは、主に次の種類。

- 一話限りのモブ・役職名のみの人物（「ディレクター」「官僚たち」「整備担当」など）
- 集団を一項目にまとめたもの（「新選組の組長一覧」「座敷童子たち」「ガルム隊」など）
- 妖魔の種族・個体で、用語集 `01_用語集/03_妖魔.md` 側で扱うほうが適切なもの（「応声虫」「山姥」「子蝿」など）

これらは無理に個人ファイル化せず、旧ファイルまたは用語集側に残す。

## 書式の統一（2026-09-18）

個人ファイルの節構成を上の基本形へ寄せた。

- `## 第4部第14話` のように `## 時系列記録` の外へ浮いていた話数見出し66ファイル分を、`### ` へ降格して `## 時系列記録` の下へ収めた。節が無かったファイルには新設した。本文は一行も変えていない（移行前後を行単位で照合済み）。
- 「現収録分001〜101時点の整理」のように古い版のまま残っていた冒頭注記172件へ、未突き合わせの断り書きを追記した。**登場しないという意味ではなく、未確認という意味**である。突き合わせが済んだファイルからこの一文を消し、版表記の数字を最新の原稿番号へ更新する。
- **2026-09-19に断り書きの書式を変えた**。`原稿102〜119との突き合わせは未実施。` のように終わりを書いていたが、これだと新しい原稿が来るたび全ファイルを書き換えることになるため、`原稿102以降との突き合わせは未実施。` という終わりを書かない形へ182件を一括変換した（変わったのはこの一文だけで、本文は照合済み）。新しい原稿が来たときは `python3 tools/stamp_unchecked.py --write` で未突き合わせのファイルへ一括で付けられる。

まだ揃っていないもの（判断が要るため保留）。

- ~~`## 遠野決戦`・`## 霊刀分配会議`・`## 5年前` のような出来事名だけの見出し~~ → **2026-09-19に整理**。70ファイルの計159節を、見出しを1つずつ「時系列の出来事か、話題別の節か」で分類し、時系列側を `### ` へ降格して `## 時系列記録` の下へ収めた（節が無いファイルには新設）。節の中に `### ` があるものは `#### ` へ繰り下げた。本文は一行も変えておらず、見出し記号を落とした行の集合が前後で一致することを70ファイルすべてで確認している。
  - 出来事名に見えても話題別と判断して `##` のまま残したもの：`伊藤誠.md` の `## 組織との関係`・`## 紅美鈴`、`メルエム.md` の `## 第三勢力との関係`、`自来也.md` の `## 組織への参加理由`。
  - 5ファイル（`キョン.md`・`ジャギ.md`・`ベルゼブブ.md`・`伊藤誠.md`・`志々雄真実.md`）は時系列の節が話題別の節をはさんで離れていたため、時系列の節を先頭側へ寄せた。節の中身は動かしていない。
- 各ファイル末尾の「旧・陣営別ノートの詳細ログ」と、上の要約・時系列記録が二重になっている箇所の整理。

## `##` 見出しの例外

検査Kは、個人ファイルの `##` 見出しのうち**出来事名・話数・時期に見えるもの**を鳴らす。それは `## 時系列記録` の下へ `### ` で入れるべきものだから。

話題別の節なのに引っかかるものだけ、下の表へ書く。**この表に無いものが引っかかると検査が鳴る。**

| ファイル | 見出し | 話題別と判断した理由 |
|---|---|---|
| `安倍晴明.md` | `## 第2部での意味` | 第2部で起きた出来事ではなく、第2部という文脈での位置づけを述べた節 |

## 参照順

人物について調べる場合は、原則として次の順で参照します。

1. `07_読書スナップショット/統合/`
2. `02_人物/個人/<人物名>.md`
3. 必要な5話スナップショット
4. 旧巨大人物ファイル
5. 必要なら原稿

この順序にすると、終盤で判明した真相だけで序盤・中盤の人物像を上書きしにくくなります。

## 個人ファイルの基本形

```markdown
# 人物名

> 現収録分時点の整理。詳細な各話ログは旧人物ノートと読書スナップショットを参照。

## 要約
- 立場
- 能力
- 人格の核
- 主な関係
- 現在の状況

## 時系列記録
- 初期
- 中盤
- 後期
- 必要なら部・章ごと

## 能力・技術

## 主な関係

## 未確定・注意
```

人物によって情報量が違うため、無理に全項目を同じ長さにはしません。情報が少ない人物は短くし、空白を推測で埋めません。

## 整理時の安全ルール

- 元ファイルの引用・出典・「提供者の指摘」を、新個人ファイルができたという理由だけで削除しない。
- 同名・別名・AA由来の人物同一性は、原稿または提供者確認なしに統合しない。
- 所属変更・敵味方変更は、過去の所属を消さず時系列で残す。
- 「現在の状況」は**現収録分時点**とし、作品全体の最終状態と断定しない。
- 初登場時の誤認・途中の仮説・後の真相が人物像に重要なら、両方残す。
- 能力評価は、作中人物の評価と客観的に確認された性能を分ける。
- 特殊条件下の最大現象を、その人物の通常時性能として扱わない。
- 夫婦・主従・陣営単位で強く結びつく人物でも、原則は1人1ファイルとする。
- 情報が少ない人物は短くする。元ネタ作品の設定で穴埋めしない。

## 今後の分割方針

参照頻度と物語上の重要度を優先し、以下の順で旧巨大ファイルから救出します。

1. 地区長・直轄部隊・監査委員
2. 大規模敵対勢力の主要人物
3. 国外勢力・研究者・式神
4. 主人公周辺の町・民間退魔師
5. 端役・一話限りの人物

新個人ファイルが十分に揃った後も、旧陣営別ファイルを削除する前には必ず照合を行います。
