# 人物ノート案内

人物情報は現在、陣営・立場ごとの5ファイルにまとまっています。追記の積み重ねで非常に大きくなっているため、将来的には主要人物を1人1ファイルへ分割する予定です。

ただし、人物の同一性・所属変更・現在の立場・伏線の意味を誤って整理しないため、**全編確認前には既存情報を削除せず、大規模な人物分割も行いません**。

## 現在のファイル

- `00_主要人物.md` — やる夫、やらない夫、つかさ、かがみ、家族など
- `01_陰陽寮.md` — 陰陽寮首脳、地区長、その配下、政府・国外関係者など
- `02_組織.md` — 敵対組織のトップ、幹部、実行役など
- `03_民間退魔師・町の人々.md` — 民間退魔師、呪具師、一般人など
- `04_妖魔・妖精・その他.md` — 特定陣営に属さない妖魔・妖精・その他

## 今後の人物項目の基本形

新規人物や、既存人物を後で分割するときは、次の形を基本とします。

```markdown
# 人物名

## 要約
- 立場:
- 能力:
- 主な関係:
- 現在の状況:

## 時系列記録
- **第○話(原稿NNN #レス)・見出し**: 出来事

## 未確定事項
- 必要な場合のみ。詳細は `../99_未確定・矛盾メモ.md` を参照。
```

「要約」は、その人物を数十秒で把握するための短い部分です。「時系列記録」は既存の細かな根拠・引用を失わないための部分です。

## 全編確認前の安全ルール

- 既存の人物記録を短縮・削除しない。
- 同名・別名・AA由来の人物同一性を勝手に確定しない。
- 所属変更を理由に古い記録を移動・消去しない。
- 「現在の状況」は、作品の続きを確認してから最終確定する。
- 主要人物を1人1ファイルへ分ける場合も、元ファイルは照合完了まで残す。

## 将来の分割方針

全編確認後、まず `00_主要人物.md` の中心人物から1人1ファイル化し、その後、巨大な `01_陰陽寮.md` を人物単位または小陣営単位に分けます。分割後も、陣営別の索引を残して「誰がどこにいるか」を探せるようにします。
