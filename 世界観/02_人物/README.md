# 人物ノート案内

人物情報は長年の追記で、陣営・立場ごとの巨大ファイルへ集積しています。現収録分001〜101を一通り確認し、読書スナップショットも作成済みとなったため、2026-09-17から主要人物の**1人1ファイル化**を開始しました。

旧巨大ファイルは証拠・詳細ログとして残し、新個人ファイルとの照合が終わるまで削除しません。

## 旧・陣営別ファイル（保全中）

- `00_主要人物.md` — やる夫、やらない夫、つかさ、かがみ、家族など
- `01_陰陽寮.md` — 陰陽寮首脳、地区長、その配下、政府・国外関係者など
- `02_組織.md` — 敵対組織のトップ、幹部、実行役など
- `03_民間退魔師・町の人々.md` — 民間退魔師、呪具師、一般人など
- `04_妖魔・妖精・その他.md` — 特定陣営に属さない妖魔・妖精・その他

これらは現時点では**削除・大幅圧縮しない**。新ファイルへ移した情報が不足していないか確認するための原記録として扱います。

## 役割分担

### 新個人ファイル

「この人物が誰で、どう変化し、現収録時点でどうなっているか」を数十秒〜数分で掴むための整理版。

### 旧巨大人物ファイル

各話ごとの細かい記録、引用、レス番号、過去に積み上げた情報を保持する証拠庫。

### `07_読書スナップショット/`

人物を「後から判明した真相」だけで平板化しないため、その時点でどう見えていたかを保存する。

人物整理で全体像が必要な場合は、

1. `07_読書スナップショット/統合/`
2. 該当人物の新個人ファイル
3. 必要な5話スナップショット
4. 旧巨大人物ファイル／原稿

の順で参照すると、終盤情報へ偏りにくい。

## 整理時の安全ルール

- 元ファイルの引用・出典・「提供者の指摘」を、新個人ファイルができたという理由だけで削除しない。
- 同名・別名・AA由来の人物同一性は、原稿または提供者確認なしに統合しない。
- 所属変更・敵味方変更は、過去の所属を消さず時系列で残す。
- 「現在の状況」は**現収録分時点**と明記し、作品全体の最終状態と断定しない。
- 初登場時の誤認・途中の仮説・後の真相が人物像に重要なら、両方残す。
- 能力評価は作中人物の発言と客観的に確認された性能を分ける。
- 特殊条件下の最大現象を、その人物の通常時性能として扱わない。

## 今後の分割順

新個人ファイルが十分に揃った後も、旧陣営別ファイルを削除する前には必ず照合を行う。
